# 反馈与建议

遇到问题、想到新功能，或只是想吐槽两句，都可以在 App 内直接提交，不用另外去找仓库地址。

**入口：设置 → 帮助与关于 → 反馈与建议。**

## 怎么提交

1. 选择类型：**建议**、**缺陷**、**其他**。
2. 填标题和详细描述（选「缺陷」时还会多一个「复现步骤」）。
3. 按需打开两项附加信息：
   - **附带环境信息**（默认开）：App 版本、Android 版本、机型、ABI、系统语言。只用于定位问题，不采集设备标识。
   - **附带最近日志**（默认关）：自动脱敏后附上最近 200 行日志。API Key、`token`/`password` 赋值、`Bearer` 令牌会被替换成 `***`。
4. 点「前往 GitHub 提交」。

App 会：

- 把反馈内容复制到剪贴板；
- 在浏览器中打开项目 Issue 页，并尽量自动填好标题和正文；
- 如果浏览器没有自动填入，长按正文框粘贴即可（内容已在剪贴板里）。

> 提交需要登录 GitHub 账号。如果手机上没有浏览器，App 会提示「内容已复制」，可以换设备或手动到仓库提交。

## 隐私注意事项

Issue 是**公开**的。提交前请确认：

- 描述里没有贴入私人代码、服务器地址或密钥；
- 日志虽然已脱敏，仍建议提交前扫一眼；
- 不需要附带日志时，把「附带最近日志」关掉即可。

## 内容去哪了

提交成功后就是一个普通的 GitHub Issue，可以直接在 Issue 里继续补充截图、讨论和跟进修复进度。

## 提交按钮没反应 / 内容没自动填入

- **没反应**：通常是设备上没有可用浏览器。此时内容已复制到剪贴板，换一台设备或用浏览器手动打开项目 Issue 页粘贴即可。
- **正文是空的**：个别浏览器会丢弃过长的预填内容。App 已自动裁剪链接中的正文，并保证完整内容在剪贴板中；粘贴完整版即可。
