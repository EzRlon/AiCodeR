# 反馈与建议

遇到问题、想到新功能，或只是想吐槽两句，都可以在 App 内直接提交，不用另外去找仓库地址，也不需要登录 GitHub。

**入口：设置 → 帮助与关于 → 反馈与建议。**

## 怎么提交

1. 选择类型：**建议**、**缺陷**、**其他**。
2. 填标题和详细描述（选「缺陷」时还会多一个「复现步骤」）。
3. 按需打开两项附加信息：
   - **附带环境信息**（默认开）：App 版本、Android 版本、机型、ABI、系统语言。只用于定位问题；另有一个每次安装随机生成的匿名标识用于去重，不含账号信息。
   - **附带最近日志**（默认关）：自动脱敏后附上最近 200 行日志。API Key、`token`/`password` 赋值、`Bearer` 令牌会被替换成 `***`。
4. 点「提交反馈」。

App 会直接把内容提交到项目的反馈收集页，由收集页归档/建 Issue；用户不需要浏览器、GitHub 账号或复制粘贴。

## 网络不好怎么办

提交失败不会丢内容：反馈先写入本地发件箱，App 下次启动或下次提交前自动重试。页面会显示「本地待提交：N 条」，联网后自动清空。

## 隐私注意事项

反馈内容是**公开**的（用于排障与跟进）。提交前请确认：

- 描述里没有贴入私人代码、服务器地址或密钥；
- 日志虽然已脱敏，仍建议提交前扫一眼；
- 不需要附带日志时，把「附带最近日志」关掉即可。

## 内容去哪了

收集页会把它归档到项目反馈记录里，开发侧在下一次同步仓库时即可看到并跟进；修复进度仍以项目发布说明为准。
