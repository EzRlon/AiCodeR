# 签名与凭据

「设置 → 签名与凭据」集中展示设备上的密钥文件，方便查看、比对与备份迁移，并在发布前检查「证书 + 口令配置」是否配齐。页面除导入外**只读**——不会修改或删除已有的密钥文件。

## 展示范围

页面按来源分三组列出：

- **统一密钥库（`~/.aicode/keys`）**：建议集中存放密钥的位置；「导入密钥」放入的文件都会到这里。
- **SSH 密钥（`~/.ssh`）**：容器内 root 用户的 SSH 目录。
- **工作区密钥文件**：当前工作区中发现的 `*.jks`、`*.keystore`、`*.p12`、`*.p8`，以及签名配套的口令配置 `keystore.properties` / `signing.properties`（自动跳过 `node_modules`、`build` 等目录）。远程模式下跳过此项。

每个文件显示大小、修改时间与**内容指纹短码**（SHA-256 前 12 位，用于快速比对是否同一份文件）。点击条目可：**导出**该文件、**复制路径**（容器视角路径，可直接粘给 AI 使用）或查看**详情**（完整指纹、路径、类别）。

::: tip 指纹是内容摘要
指纹按文件**内容**计算（`sha256:` 全串在详情里），不是证书指纹；超过 4 MB 的文件不计算，详情中会注明。
:::

## 导入

页面顶部「导入密钥」→ 在系统文件选择器中**多选**文件 → 复制进统一密钥库 `~/.aicode/keys`。同名文件自动改名为 `名称-2.扩展名`、`名称-3.扩展名`……不会覆盖已有文件。

## 导出

- **导出全部（zip）**：把列表中的全部文件打包为 zip——内部按来源分目录（`keys/`、`ssh/`、`workspace/`），并附一份 `manifest.txt` 清单（文件名、大小、时间、指纹、路径）。发布就绪检查认定的口令配置一定在包里（包括 `<证书同名>.properties` 这类自定义命名），与「打包发布资产」口径一致。
- **单条导出**：条目菜单里选「导出」，单独保存该文件。
- **打包发布资产**：仅收录打正式包必需的最小集——证书 + 配套口令配置 + 逐文件 SHA-256 校验和 + 恢复说明。就绪检查未全绿时拒绝打包。

「导出全部」不含任何密码，适合传阅与盘点；**「打包发布资产」含明文口令**（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`），只能加密保管、勿入库勿转发。发布签名的 `*.jks` 通常就在统一密钥库 `~/.aicode/keys/` 里（由构建配置引用）。

::: warning 签名密钥建议多渠道备份
发布签名密钥一旦丢失将无法找回。导出的 zip 请保存在设备之外的安全位置。
:::
