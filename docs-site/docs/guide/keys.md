# 签名与凭据

「设置 → 签名与凭据」用来给**正式包准备签名**：检查证书、口令配置，以及 Gradle 真正读取的项目 `app/keystore.properties` 是否配齐。页面也集中展示设备上的密钥文件，方便查看、比对与备份迁移。

## 当前项目

页面只读显示**当前项目**：当前工作区就是当前项目，切换工作区后页面会自动重扫，不再提供独立的项目选择器。切换工作区前请先在聊天页停止运行中的任务，否则它仍会在旧项目里继续。

普通用户按「发布就绪」清单从上往下补齐即可，不需要记 Gradle 配置。

## 发布就绪检查

Gradle 打正式包时读取的是项目里的 **`app/keystore.properties`**（不是证书同目录的同名文件）。页面会优先检查这个位置，逐项给出结论与「下一步」：

| 检查项 | 通过条件 | 不通过时怎么办 |
| --- | --- | --- |
| 证书 | 找到 `.jks` / `.keystore` | 导入发布证书，或把证书放进项目 |
| 口令配置 | 找到 `app/keystore.properties`（也兼容项目根目录 / 证书同目录） | 在项目 `app/` 下创建该文件 |
| 四个字段 | `storeFile` / `storePassword` / `keyAlias` / `keyPassword` 都非空 | 补齐缺的字段 |
| storeFile | 按项目 `app/` 目录解析后，文件真实存在 | 把证书放到该路径，或修正 `storeFile` |
| 别名 | 证书里能找到 `keyAlias` | 用 `keytool -list` 查看真实别名并改正 |
| keyPassword | App 无法离线验证，标为「无法自动验证」 | 发布前跑一次 `assembleRelease` 终检 |

「无法自动验证」显示为 ⚠，**不算**未就绪；只有 ✗ 的阻断项才需要先修。容器里通常没有 `keytool`，所以别名也经常落在这个状态——这不代表口令配错。

## 展示范围

页面按来源分三组列出：

- **统一密钥库（`~/.aicode/keys`）**：建议集中存放密钥的位置；「导入密钥」放入的文件都会到这里。
- **SSH 密钥（`~/.ssh`）**：容器内 root 用户的 SSH 目录。
- **工作区密钥文件**：当前项目中发现的 `*.jks`、`*.keystore`、`*.p12`、`*.p8`，以及 `keystore.properties` / `signing.properties`（自动跳过 `node_modules`、`build` 等目录）。远程模式下跳过此项。

每个文件显示大小、修改时间与**内容指纹短码**（SHA-256 前 12 位，用于快速比对是否同一份文件）。点击条目可：**导出**该文件、**复制路径**（容器视角路径，可直接粘给 AI 使用）或查看**详情**（完整指纹、路径、类别）。

::: tip 指纹是内容摘要
指纹按文件**内容**计算（`sha256:` 全串在详情里），不是证书指纹；超过 4 MB 的文件不计算，详情中会注明。
:::

## 导入

页面顶部「导入密钥」→ 在系统文件选择器中**多选**文件 → 复制进统一密钥库 `~/.aicode/keys`。同名文件自动改名为 `名称-2.扩展名`、`名称-3.扩展名`……不会覆盖已有文件。

如果项目的 `storeFile` 指向统一密钥库（如 `storeFile=/root/.aicode/keys/aicode-release.jks`），导入后就能直接通过检查；否则把证书复制到项目里 `storeFile` 指向的位置。

## 导出

- **导出全部（zip）**：把列表中的全部文件打包为 zip——内部按来源分目录（`keys/`、`ssh/`、`workspace/`），并附一份 `manifest.txt` 清单（文件名、大小、时间、指纹、路径）。发布就绪检查认定的口令配置一定在包里（包括 `<证书同名>.properties` 这类自定义命名）。
- **单条导出**：条目菜单里选「导出」，单独保存该文件。
- **打包发布资产**：仅收录打正式包必需的最小集——证书 + 配套口令配置 + 逐文件 SHA-256 校验和 + 恢复说明。就绪检查未全绿时拒绝打包。

**「导出全部」与「打包发布资产」都可能含明文口令**：前者按原样打包清单里的全部文件，后者只带发布必需的最小集，两者的 zip 内都有 `keystore.properties`（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`）。只能加密保管、勿入库勿转发；压缩包内的 `manifest.txt` 清单本身不含密码。

::: warning 签名密钥建议多渠道备份
发布签名密钥一旦丢失将无法找回。导出的 zip 请保存在设备之外的安全位置。
:::
