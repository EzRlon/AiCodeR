# 随记（速记浮窗）

开会时突然想到一个点子、写代码写到一半想起要改个需求、或者只是想先记两句话再继续聊——不用切出去打开别的记事本。

**入口**：聊天界面顶部，**新建会话左边**的「随记」按钮（纸张图标）。点一下弹出浮窗，再点一下收起。

## 浮窗能做什么

- **Markdown 源码编辑**：浮窗复用代码编辑器的 sora-editor + TextMate Markdown 语法，直接编辑 `.md` 源码；带行号、撤销栈，窗口变宽变窄都会自动换行，不会横向滚动。
- **纵向格式条**：编辑器右侧是竖排的 **待办 / 列表 / 加粗 / 斜体 / 撤销 / 重做**，点一下插入对应 Markdown 记号；下方状态栏显示「第 N 行 / 共 M 行」与 Markdown。
- **不挡会话**：浮窗浮在聊天界面之上，拖动标题栏可以挪位置，拖右下角可以改大小；点 `—` 最小化成一个圆球，点圆球恢复。位置和尺寸会记住。
- **自动保存**：停止输入约 0.8 秒后自动写盘，标题栏会显示「保存中… / 已保存」；关闭浮窗还会再存一次。

> 这是源码编辑器，不是所见即所得：表格、代码块、标题等直接按 Markdown 语法输入即可；浮窗不再内置会误插空表格/分割线的重型工具栏。

## 写好之后

标题栏右侧是图标动作，与润色按钮同一套样式：

| 图标 | 作用 |
| --- | --- |
| 列表 | 在已有随记之间切换；菜单底部是「新建随记」。当前这篇会打勾。 |
| 羽毛 | **润色**：把草稿改写成清晰、专业的表述（与输入框的润色是同一条链路，同一模型）。 |
| 回旋箭头 | **撤销润色**：只在刚润色过时出现。 |
| 纸飞机 | **发给 AI**：把当前内容直接发给当前会话的 agent 接任务，不用复制粘贴。 |

> 润色和发送都依赖当前会话：没有打开会话时，发送会提示失败。发送后原文仍保留在随记里，方便继续补充。

## 文件存在哪

项目工作区下的 `.aicode/notebook/`，一篇随记一个 `.md` 文件，例如：

```text
~/workspace/.aicode/notebook/随手记-1115-1430.md
```

- 属于当前项目，换项目就是另一套随记；
- **不会**自动进入 AI 的知识库或上下文——它是你的草稿，只有点「发给 AI」时才会交给模型；
- 可以用文件管理器/编辑器直接打开、备份或挪走。

## 常见问题

- **浮窗里的字打不出来**：先点一下正文区域再输入；如果键盘挡住了编辑区，浮窗会自动上移。
- **找不到之前写的内容**：点浮窗底部的「切换」看列表；如果列表为空，检查当前工作区是否切换过（随记按项目存储）。
- **发送按钮没反应**：确认当前会话存在且没有被上下文阈值暂停；提示「先写点内容再发送」说明草稿是空的。
- **点错格式按钮**：格式只作用于当前选区/段落，点「撤销」即可回退上一步。
