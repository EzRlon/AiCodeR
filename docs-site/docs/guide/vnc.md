# VNC 悬浮窗

对话界面内置的 VNC 悬浮小窗，可以把容器里的图形画面（桌面程序、浏览器测试画面等）直接悬浮在聊天上方，不用切换到别的软件。

## 打开与收起

在聊天界面右上角，「新建会话 ➕」按钮左边有一个显示器图标按钮：

- **单击**：弹出悬浮小窗（小窗开着时按钮会高亮）。
- **双击**：收起小窗。
- 小窗标题栏右侧的 ✕ 也能收起。

首次打开时，App 会在容器里自动安装并启动图形服务（Xvfb + VNC 服务 + 极简桌面），需要联网，第一次会等待几十秒到几分钟，之后秒开。

启动后你会看到一个**极简桌面**：一个可拖动/缩放的终端窗口（标题 AiCode Shell），以及最基础的窗口边框。它只占约 10MB 磁盘、几十 MB 内存，足够在手机上看容器里的图形程序；不会预装浏览器或完整桌面。

## 小窗操作

小窗很像手机系统里的自由小窗：

| 操作 | 方式 |
| --- | --- |
| 移动位置 | 拖动小窗顶部标题栏 |
| 改变大小 | 拖动小窗右下角 |
| 钉住（固定位置防误拖） | 标题栏的锁形图标，高亮为已钉住 |
| 最小化 | 标题栏的下箭头图标，缩成悬浮球（点球恢复），位置沿用窗口位置 |
| 全屏 / 还原 | 标题栏的全屏图标，全屏后按返回键退出 |
| 关闭 | 标题栏的 ✕ |

标题栏左侧的状态灯表示连接状态：黄色 = 正在准备服务，蓝色 = 连接中，绿色 = 已连接，红色 = 启动失败（画面区会显示原因和重试按钮）。

## 自动弹出

当 AI 在容器里启动了图形程序（比如运行带界面的测试、打开图形浏览器）时，悬浮窗会**自动弹出**，你能实时看到 AI 正在操作的画面。如果觉得打扰：手动收起后 10 分钟内不会再次自动弹出。

小窗里的画面与 AI 操作的是同一个画面源：比如 AI 通过浏览器工具操作网页时，悬浮窗里看到的就是它正在操作的那个浏览器。

## 输入与剪贴板

- **触摸**：点按画面 = 鼠标左键；双指拖动可平移/缩放视图。
- **中文输入**：先在手机上复制文字，点标题栏的剪贴板图标，再在 VNC 画面里粘贴。
- **英文/数字**：可外接物理键盘直接输入。
- 画面里复制的内容会自动同步到手机剪贴板。

## 适用范围

- 仅**本地容器模式**支持（远程 SSH 模式下显示器按钮不会出现，因为画面在远端服务器上，传不回手机）。
- 服务只在容器运行期间存活，收起悬浮窗不会停止服务；下次打开秒连。

## 常见问题

**一直显示「正在准备容器图形服务」？**
首次使用需要下载组件，取决于网络，请耐心等待；若超过 10 分钟或提示失败，检查容器网络（终端里 `ping mirrors.cloud.tencent.com`）后点「重试」。

**画面黑屏或显示连接失败？**
服务可能还没就绪，等状态灯变绿；若长期失败，可在终端执行 `pgrep -f websockify` 确认服务是否在跑，不在跑的话重新点开悬浮窗会自动再拉起。

**画面卡顿？**
VNC 是像素流传输，高动态画面在手机上帧率有限；静态界面（网页、表单操作）不受影响。
