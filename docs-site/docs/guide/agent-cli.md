# AI 智能体（终端 CLI）

在许愿码的容器终端里安装和运行主流 AI CLI 编程助手：Claude Code、Codex、OpenCode。安装、登录、使用全部在容器内完成，不依赖电脑。

## 打开方式

聊天页顶栏的「智能体」图标（终端图标左侧）会打开 AI 智能体面板，列出三个智能体及其安装状态。

## 安装

- 状态显示「未安装」时点「安装」：App 会新开一个终端标签自动执行 `npm install -g`，整个过程可在终端里看到进度（约 1 分钟，取决于网络）。
- 安装完成后面板自动复检并显示版本号；也可切到终端查看输出。
- 首次安装会自动完成容器初始化（rootfs 解压），耗时会更长。
- 如果提示「未检测到 Node.js/npm」：在终端里执行 `aicode` 命令，选择安装 Node.js 环境后重试。

三个智能体锁定了实测可用的版本，保证一键安装可复现；需要更新版本时点「重装」即可。

## 启动与登录

点「启动」会新开一个终端标签进入该 CLI 的交互会话（大屏下自动切到右侧终端栏，窄屏跳转终端页）。

首次使用需要登录：

- **Claude Code**：启动后按提示复制登录网址到手机浏览器，完成登录后把授权码粘贴回终端（长按终端可粘贴）。
- **Codex**：启动后按提示完成浏览器登录，或执行 `codex login`。
- **OpenCode**：启动后输入 `/auth` 选择供应商并粘贴 API Key。

登录一次长期有效；之后点「启动」直接进入会话。

## 工作模式

在聊天会话里使用外部引擎时，左下角的构建 / 计划 / 自动模式同样生效，由各引擎自己的权限能力实现（例如 Codex 用沙箱档位、OpenCode 用只读 agent）。各引擎的具体表现见[工作模式](/guide/modes#外部引擎-claude-code-codex-opencode)。

## 交付文件

三个引擎都能像内置引擎一样交付文件：AI 调用 `send_file` 工具后，文件会在聊天里显示成卡片（APK 可直接安装、图片可在应用内查看），并同时出现在抽屉的交付页里，副本会导出到手机「下载/AiCodeR」。

直接跟它说「把装好的包发给我」即可，不需要额外配置。

## 常见问题

- **安装很慢或失败**：安装器会自动优先使用国内 npm 镜像、失败回退官方源；仍失败多为网络/代理问题，可在终端里重试，或手动加 `--registry=https://registry.npmmirror.com`。注意 `aicode` 的「换软件源」只换 apk/apt 系统源，不影响 npm。
- **启动后提示命令不存在**：智能体未安装成功，回到面板重新安装。
- **模型怎么配**：CLI 首次启动会引导选择登录方式或模型供应商；也可以在许愿码「设置 → AI 供应商」里给 App 内置对话配模型，两者互不影响。
