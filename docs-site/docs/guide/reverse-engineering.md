# 逆向分析（REA）

「许愿码」已集成 **REA（Reverse Engineer Anything）**：不用写代码，直接对话就能分析**没有源码的成品软件**是怎么实现的——App、APK、JS/Electron 包、归档文件等，结论都带证据与局限说明。

## 三步用起来（全自动安装，一次性）

1. **一键装环境**：左栏 → **逆向分析** → 点「**安装逆向分析环境**」（自动下载分析引擎，约几分钟；失败可重跑，已装的会自动跳过）。也可在终端执行 `aicode`，在场景菜单中选「**逆向分析（REA）**」
2. **一键接入**：同一页面点「**一键接入（添加到 MCP）**」（保存即生效）。也可走 设置 → **MCP** → 添加 → **推荐区** → 点「**REA 逆向工程**」→ 保存
3. **开用**：回到对话，直接说：

> 帮我分析一下 `~/workspace/xxx.apk` 是怎么实现的

AI 会自动读取、反编译、追踪引用，把「这个功能是怎么实现的」讲清楚并附证据。

## 能分析什么

| 类型 | 说明 | 依赖 |
|---|---|---|
| **Android APK**（含 Flutter 识别） | 清单/权限/类与方法反编译/静态引用追踪 | 环境安装自动备好 |
| JS / Electron 包（目录或 ASAR） | 模块、导入关系、IPC 通道、路由 | 内置，无需额外引擎 |
| 归档包（ZIP / APK / IPA / MSIX 等） | 成员清单、结构与发现 | 内置 |
| Go / Rust 二进制元数据 | 编译版本、依赖清单（无需装 Go/Rust） | 内置 |
| **暂不支持**：native 深度反编译 | 需要 Ghidra/IDA 等重型引擎，后续评估 | — |

## 怎么问（示例）

- 「分析这个 APK 的登录流程——密码是怎么加密、发到哪里的」
- 「这个 App 的某个动画/界面效果怎么实现的，帮我照着做一个」
- 「看看这个包的接口地址都在哪定义的」
- 「这个 App 里某个按钮点下去都做了哪些事（从代码里追）」

## 常见问题

- **第一次分析有点慢？** 引擎首次启动 + 加载 APK 需要几秒到几十秒（27MB 的包实测约 11 秒加载），大文件更久；之后会快一些。
- **AI 说工具不可用？** 说明步骤 1/2 没完成，或需要重启一次 App（新会话）让 MCP 重新连接。
- **分析结果里有「未知」？** 静态分析只能看「代码写了什么」，推测不了「运行时一定会怎样」；REA 的结论会明确区分「观察/推断/未知」——这正是它的可信之处。
- **下载失败？** 环境安装支持多源重试，网络好转后重跑「逆向分析」场景即可（已装部分会跳过）。

## 合规提醒

本能力仅用于分析**你拥有或已获授权分析**的软件（学习理解、兼容互操作、安全研究、恢复自有代码等正当用途）。
请勿用于破解授权、绕过保护或其他未经授权的用途。
