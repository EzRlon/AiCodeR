# 测试包与一键安装

在工作区里构建出的 APK 会集中出现在「测试包」列表里，点一下即可唤起系统安装器安装到本机——整个闭环不用离开许愿码。

## 使用

1. 打开聊天页左侧边栏，点「测试包」。
2. 页面自动扫描当前工作区里的安装包（`.apk` / `.apks` / `.xapk`，含各 flavor 的构建产物），按修改时间从新到旧排列，显示路径、大小与时间。
3. 点任意一条 → 若尚未授权「安装未知应用」会先引导去开启，之后拉起系统安装器完成安装。
4. 新构建的包不会自动出现时，点右上角「重新扫描」。

## 说明

- 扫描范围为整个当前工作区（深度 8 层内），最多列出最近修改的 50 个。
- 安装走系统安装器，与从文件管理器点安装包是同一套机制；解析失败或格式不支持时会有对应提示。
