# 能力地图（场景速查）

许愿码里的 AI 不只是「会读写文件和跑命令」——它还能调动一批软件能力：规划与拆解、分身协作、知识沉淀、定时执行、界面验证、设备操作等。本页把软件能力按「场景 → 能力」整理成一张地图。

AI 在任务中会对照本页选择与组合能力；你也可以用它了解许愿码能帮你做什么。

## 一、开发与协作

- **三种模式（Build / Plan / Auto）**——Build 直接执行；Plan 只读规划、先出方案；Auto 自动放行、全速推进。AI 在需要规划时会申请进入计划模式，你在输入区模式图标里切换。→ [三种模式](/guide/modes)
- **子代理**——派生独立小助手并行干活：代码库调研、批量定位、独立审查，主对话只收结论摘要。AI 用 `task` 派发；你可在设置中自定义角色、模型与工具范围。派发三件配套：①**任务书模板**——把「目标/上下文/边界/产出/预算」五要素写成 `~/.aicode/task-briefs/<名>.md`，派发时 `task(brief="<名>")` 引用，模板正文自动前置；②**任务期工具收敛**——`task(tools="readFile,list,search")` 只给该任务需要的工具（只收窄不放开、支持 `mcp__server__*` 通配，仅本次派发生效）；③**报告归档**——子代理结束自动把结论存进 `~/.aicode/subagent-reports/`，子会话删掉也能用 `task(action="read")` 取回、`task(action="list")` 看归档，同范围审查可先查归档避免重复跑。切到 CLI 引擎时，已启用的子代理会随回合自动映射成引擎侧 agent（Claude Code 经 `--agents`、OpenCode 写进配置的 `agent` 段，只映射描述与提示词；OpenCode 侧与自带 agent（build/plan/explore/general 等）同名的会跳过；名称含中文或空格的不会映射，CLI 侧 agent 名需 ASCII 标识符），无需手动配置。→ [子代理](/guide/subagent)
- **全流程托管（专家团）**——给会话挂上一组角色（如产品 + 架构 + 前端 + 质检），一键进入专家团协作。聊天页顶栏入口召唤（选择面板按内置/全局/项目分组，展开可见每个团的成员及其名字）；召唤后顶栏按钮高亮、输入栏上方出现**团队实时面板**（收起态两行：团名 + 实时摘要「N/M 在忙 · X 已完成 · Y 待派」；点按向上展开，上限约 1/4 屏高，内容多可滚动，无人操作时自动轮播展示各成员当前任务，触碰即停、全员空闲自动停），成员名字与状态在对话记录、侧栏子代理行同步显示，随时知道当前谁在干活、干到哪一步。团长按全生命周期节点自动派人（需求澄清→方案→实现→独立审查→交付），用户中途报 bug/改需求/追加范围时自动对号派人。AI 识别到项目级诉求（新项目/跨模块大功能）时会主动建议召唤对应团，也可通过 summon_team 工具直接召唤（免手动，不指定团队时返回清单与适用场景供引导）。
- **项目任务账本**——长期项目跨会话交接不再靠翻聊天记录：AI 用 `taskLedger` 工具把任务记成状态表（queued 排队 / doing 进行中 / done 完成待验收 / accepted 验收通过，只前进不回退），存在项目内 `.aicode/notes/task-ledger.md`，可随 git 与备份走。新会话开工先看 doing/queued 接续，不重做已完成项。
- **检查点与撤销**——AI 每次改文件前自动快照。改动不满意时，「这一轮重来」（代码与对话一起回退），或只回退其一。→ [检查点与撤销](/guide/checkpoint)
- **消息类型**——发送前给消息打一个类型标签（缺陷修复 / 方案计划 / 调研研究……），AI 据此调整处理策略。输入区细标签行选择，发送后自动重置。
- **交接提醒与自动交接**——对话上下文过半时，回合结束会提示建议 `/compress` 压缩或开新会话接手（默认 50%，每会话最多两次）；正常情况下自动压缩会先接管（默认 70%），自动交接退化为兜底：默认达到 93% 才暂停当前会话、生成接手摘要并直接开新会话接力（交接会带上目标/模式/专家团；设置 → 偏好设置可开关自动交接与调整阈值）。被压缩归档的内容不会丢：AI 可用 `recall` 工具按关键词从跨会话档案取回原文。
- **会话目标（Goal）**——输入 `/goal <目标>` 后 AI 围绕目标自主循环推进：自动连续工作、用证据审计完成度，达成或受阻才停（`/goal pause` 暂停、`/goal resume` 续跑、`/goal clear` 清除）；轮次与 token 预算可在设置 → 偏好设置调整。→ [会话目标](/guide/goal)
- **悬浮球（精灵球）**——设置 → 偏好设置开启后，切到其它 App 时仍有一个可拖动的精灵球：待机只露一枚贴边小胶囊，颜色即状态（绿=进行中带 600ms 透明度呼吸/红=失败/灰=空闲）；点击展开为圆球+弹出 **mini 会话工作窗口**（右下角把手可拖拽调大小、尺寸记忆）：能看最近消息流与当前会话标题、直接发消息、停止任务、对待审批请求直接允许/拒绝、看待办进度、一键回会话；拖拽松手自动吸附就近边并缩回待机胶囊（需「显示在其他应用上层」权限；不读屏、不模拟操作）。
- **交付物页**——左侧栏「交付物」页跨会话聚合 AI 交付的安装包与文件（AI 发进会话的附件，按当前工作区过滤），按后缀类型分组、组内时间倒序；点行或长按可安装/打开、用 MT 管理器或文件管理器打开、分享、复制路径，并可**仅从列表移除**或**彻底删除**（后者连带删除容器/工作区文件与已导出的真机副本，需二次确认）。文件只在真正打开/分享/安装时按需导出到手机「下载/AiCodeR」，不预先占用空间。
- **审批通知直达与实时进度**——设置 → 后台运行可开启：AI 在后台等审批/回答时弹通知、通知栏直接批准或拒绝；AI 工作中有常驻实时进度通知（Android 16 支持提升到状态栏）。
- **自我改进模式**——开启后 AI 会反思表现，把改进沉淀为技能或提示词片段（保存在升级不丢的配置目录）。→ 设置 → 偏好设置
- **发版前优化审查（optimizer）**——正式包编译前自动拉起的多维优化审查子代理：性能/功耗/架构/屎山六维体检（与 qa 的正确性审查互补，不重复报告），产出带行号的优化清单；审查范围（全盘 / 仅当前批次）会先询问用户，未表态则按规则自动决策。→ 设置 → 子代理
- **代码智能四件套（code-intel）**——大项目里找实现、拉调用链不再盲搜：ctags 符号索引（找定义/列类结构）＋ repo-map 全仓速览 ＋ callchain 调用链 ＋ ast-grep 结构化搜索，AI 探索代码前按内置技能 code-intel 的 SOP 用它们，省 token、准、快。用法：容器内对 AI 说「给当前项目建索引」建/重建 `tags`；环境未装时终端 `aicode` 选「代码智能」场景（或 AI 自动跑 `provision.sh --install codeintel`）；项目越老索引越全，大改后 AI 会重建索引。

## 二、知识与沉淀

- **自动记忆**——AI 主动记录用户偏好、项目约定与踩坑经验，跨会话生效；分全局与项目两级，可查看与增删。→ [记忆与项目规则](/guide/memory)
- **技能**——把一类任务的标准流程与知识写成「专项能力包」，AI 遇到相关任务自动按需加载。→ [技能](/guide/skills)
- **用户脚本**——把验证过的自动化固化成命名脚本，容器内运行、反复复用：AI 用 `run_script` 工具列出/固化/运行 `~/.aicode/scripts/` 下的脚本（`.sh` / `.py` / `.js` / `.mjs`；首行注释即描述，运行结果含输出与退出码，缺解释器先装对应场景）；脚本存在配置目录，随备份/迁移走，容器终端里也能直接执行（`/root/.aicode/scripts/`）。手动管理同一批脚本在「设置 → 脚本」：列表显示解释器、描述与上次运行，可新建（选后缀建模板后进文件编辑器）、运行（输出内联展示、长输出折叠）、左滑删除。
- **省 Token 内置技能**——`token-saver`（输出过滤、精确读取、子代理带回摘要等操作纪律）与 `context-compression`（压缩时机、应固化的信息、与交接配合）随 App 内置、升级自动更新；AI 遇到相关任务自动按需加载，也可用 `/技能名` 手动触发。→ [技能](/guide/skills)
- **内置设计与规划技能**——界面任务加载 `frontend-design`（美学方向与排版决策）与 `ui-ux-pro-max`（本地检索配色/字体/图标/UX 规则库，含交付前检查项）；大活规划链用 `brainstorming → writing-plans → executing-plans → verification-before-completion` 四技能（发散澄清 → 写计划 → 按计划执行 → 完工前证据验证）；均随 App 内置、升级自动更新。→ [技能](/guide/skills)
- **内置精简与评审技能（ponytail）**——怕代码越写越臃肿：`ponytail` 用最少的新代码完整解决问题（绝不砍校验、防数据丢失、安全），档位 `/ponytail lite|full|ultra`；`ponytail-review` 评审一次改动（缺陷/安全/负载/缺测试/性能/可删可并，并对照任务清单核对漏做与夹带，用深模块/删除测试/接缝纪律判断结构该不该存在），`ponytail-audit` 审计整个仓库并按严重度排序，`ponytail-debt` 把代码里 `shortcut:` 注释汇成技术债账本。前两者读关联代码而非只看 diff，每条发现都给具体情形与最小修法。均随 App 内置、升级自动更新。→ [技能](/guide/skills)
- **内置调试技能（systematic-debugging）**——遇到 bug、构建失败、崩溃、性能回退时自动加载：铁律是「没有一条能红的命令，不许猜原因」，先造出针对该 bug 的紧反馈回路（失败测试/HTTP 脚本/回放现场/二分等十种手段，必须秒级、确定、可无人值守），再做最小化复现、3–5 个可被推翻的排序假设、带唯一前缀的埋点，修完写回归测试并统一清理调试日志；真机必须人操作时用配套的人在环脚本。连续 3 版修不好则转质疑架构。随 App 内置、升级自动更新。→ [技能](/guide/skills)
- **在线商店**——在设置里浏览并安装社区技能（claudemarket.ai）、MCP 服务器（官方 Registry）与内置专家团（成套团队：软件开发/产品设计/美工设计/调研等，一键装入团队与成员角色）：搜索/分页/一键安装；点任意条目弹详情（中英名称与描述对照、meta、来源链接、安装按钮）；「安装 ≠ 启用」，装完默认不生效，确认后再启用；**安装安全扫描**：所有商店条目安装前过本地规则扫描（零网络零模型），命中可疑特征弹黄色警示可「我已知晓风险继续装」，命中高危特征红色拦截需二次显式放行，详情弹层展示扫描结论与命中详情；专家团装好后在聊天页「召唤专家团」使用，也可在设置 → 专家团里逐个启用/停用或删除（删除只移除该团定义，成员专家保留）。→ 设置 → 在线商店
- **子代理独立模型**——设置 → 默认模型 → 智能体模型：主代理与每个子代理（内置专家/自定义角色）可分别选模型或「跟随主代理」；自定义角色定义里显式配置的模型优先于设置页覆盖。
- **自定义提示词**——覆盖或新增系统提示词片段，精确调整 AI 的行为规则。→ [自定义提示词](/guide/custom-prompts)
- **笔记模式**——Markdown 文件可在编辑器里切换所见即所得模式，像记笔记一样整理文档。
- **记忆图谱**——把项目、会话与子代理画成一张可点选的图，快速回到某条工作线索。聊天页顶栏入口。「会话」页每条线索带模式 / 执行引擎 / 子代理数量标签与 token 构成条（新增输入 / 缓存 / 输出），可只看进行中或按消耗排序；顶部四格汇总线索数、进行中、累计 token 与缓存命中率。

## 三、自动化与长任务

- **定时任务 / 定时 Plan**——到点自动执行：「定时任务」可执行一条容器命令、按计划运行一个用户脚本（成功静默、失败必报），或给 AI 一条指令由它无人值守自主完成（预授权范围内自动放行、超范围等通知授权，10 分钟无人应答自动拒绝）；「定时 Plan（长任务）」先聊出完整计划、批准后从计划审批面板排期，到点在新会话中无人值守自主施工（单次上限 12 小时）。入口：长按会话输入区的模式图标（Build → 定时任务；Plan → 定时 Plan），或长按顶栏「+」；排期与启停在设置 → 定时任务管理。→ 设置 → 定时任务
- **后台运行保活**——AI 执行任务期间自动保活防止中断；也可手动开启「空闲常驻」，让终端里自行运行的长命令不被系统回收。→ [后台运行](/guide/background-run)
- **工具钩子（Hooks）**——AI 每次调用工具前后自动运行你写的脚本：静态检查、拦截危险操作、补充上下文。→ [工具钩子](/guide/hooks)

## 四、界面与验证

- **标注中心（统一画布）**——发现界面问题或想改的地方：侧栏进「标注中心」，一块画布 + 一条工具架全流程同界面完成，不再有跳页的第二套编辑器：未定格时画布透明叠在真实界面上（弹窗照弹、按钮照点，可直接圈画，「选择」工具可点中真实组件加文字/画箭头），点「定格」抓整屏（含已打开的弹窗）为底图后精画，支持双指缩放平移；按类型（bug / 要改 / 不要 / 优化）保存入账本；工具架「账本」滑出合流面板（标注 + 修复账本、状态徽章流转、点标注条目载入画布补画后更新）；最后「汇总发给 AI」：汇总文本每条附结构化坐标区间（框选/箭头/直线/笔迹/文字的归一化百分比位置 + 附注）+ 图片附件注入聊天输入框，AI 无需只靠看图猜位置。→ [标注中心](/guide/annotations)
- **Web 预览**——容器里跑的前端服务直接在内嵌浏览器打开，改完即刷；大屏下与聊天并排。→ [Web 预览](/guide/preview)
- **VNC 悬浮窗**——把容器图形画面悬浮在聊天上方；AI 启动图形程序时自动弹出，可实时看它操作。→ [VNC 悬浮窗](/guide/vnc)
- **交付物与一键安装**——AI 交付的安装包与文件跨会话集中列出，APK 点一下装到手机，其它文件按需导出到「下载/AiCodeR」。→ [交付物与一键安装](/guide/deliverables)
- **通知栏批准**——AI 请求工具授权时，可直接从通知栏批准或拒绝，不必切回 App。→ [工具授权](/guide/permissions)
- **工具授权中心**——给每个工具设置权限档位（自动允许 / 每次询问 / 禁止），预置「日常 / 离开模式 / 只读演示」档案一键套用；授权记录里可回看每次批准与拒绝。→ [工具授权](/guide/permissions)
- **守夜守护（无人值守）**——离开/睡觉时让 AI 继续推进：危险操作自动拒绝并给出改写引导、弹窗超时自动拒绝、计划审查自动通过，不无限等待；授权记录可回看被拒动作。设置 → 工具授权 → 守夜守护。（**1.13.0 起**）

## 五、外部与设备

- **MCP 服务器**——接入外部工具能力：浏览器自动化、多模型并行咨询、专用服务等；添加面板「推荐」区内置 Context7（最新库/框架文档检索，远程 HTTP 零安装、默认不启用）可一键添加。顾问团、分析台不再预置 MCP 条目：装好对应插件并开启后，条目由插件自动挂上。→ [MCP 服务器](/guide/mcp)
- **模型顾问团（multi-llm）**——把 ChatGPT / Claude / Gemini / Grok / 通义千问 / DeepSeek 网页版接入为 MCP 工具，AI 可直接咨询其他模型并汇总意见（如「问问 ChatGPT 对这个方案的看法」）。用法：设置 → 插件 → 原生插件安装「顾问团」并打开开关（首次开启会装 chromium 等依赖），侧栏出现「顾问团」入口后才可用；首次使用在 VNC 小窗（127.0.0.1:5901）登录各网站，之后对话即可。未安装插件时，App 里不会出现该入口、MCP 条目或相关提示。→ [插件](/guide/plugins)
- **本地模型（llama.cpp 离线推理）**——在容器里装 llama.cpp 推理引擎（Alpine musl 原生包，旧版自动挂 v3.24 community 跨版本源补装），启动后即 OpenAI 兼容服务，App 把它当一个本地 provider：离线可用、小任务零 token 成本；推理速度取决于设备性能，模型需另行下载（示例 Qwen2.5-0.5B-Instruct Q4_K_M 约 470MB，hf-mirror 多源，默认不自动下载）。终端 `aicode` 选「本地模型」场景装引擎（脚本只装不启动，无常驻进程）；手动启动 `llama-server -m <模型.gguf> --host 127.0.0.1 --port 8080` 后，设置 → 模型 → 添加自定义 provider（baseURL `http://127.0.0.1:8080/v1`，apiKey 留空；或用预设「本地模型（llama.cpp）」一键填充）；llama.cpp 装不上时可降级装 Ollama（gcompat + 官方包，可选不阻塞）
- **REA 程序分析**——分析没有源码的成品软件（App / APK / JS-Electron 包 / 归档包等）是怎么实现的：解释功能原理、定位实现代码、复刻某功能；结论带证据与局限。用法：设置 → 插件 → 原生插件安装「分析台」并打开开关（首次开启自动装引擎、挂 MCP 白名单预设），之后侧栏出现「分析台」入口即可使用（工作台自带：首次知情告知书（勾选同意后不再弹）与常驻合规横幅、环境三态判定与动作引导、MCP 真连接状态（失败显原因可重连）、分析目标支持 SAF 选择 APK/文件导入与样本删除（自动列工作区 APK/DEX/JAR/SO/JS 等样本，按修改时间排序）、学习任务模板、可用工具清单与 node/java/jadx 组件实测）；之后对话即可（如「帮我分析这个 APK 的登录流程」）。未安装插件时，App 里不会出现该入口、MCP 条目或相关提示。仅限你拥有或获授权分析的软件。→ [程序分析](/guide/program-analysis)
- **内置浏览器**——AI 可后台自动操作网页并截图；你也可以自己浏览（书签、历史、多标签）。→ [内置浏览器](/guide/browser)
- **联网检索**——AI 按需搜索与抓取网页资料（websearch / webfetch）。
- **Shizuku**——用户授权后，AI 可在宿主 Android 系统上执行命令（ADB 级）；每次调用弹窗确认。→ [Shizuku 工具](/guide/shizuku)
- **远程 SSH**——执行环境可放到远程服务器，工作区文件读写经由 SSH 完成。→ [远程 SSH](/guide/remote-ssh)
- **工作区同步与内置 FTP**——把工作区同步到 SFTP/FTP 服务器；也可在手机上开 FTP 服务，用电脑管理 `projects/` 下的项目文件。→ [工作区同步](/guide/sync)
- **远程管理**——局域网网页服务：用电脑浏览器浏览、上传、下载、重命名和删除手机外部存储里的文件。每次开启会生成一次性访问令牌，页面地址形如 `http://<手机IP>:8300/?t=<令牌>`，请从 App 里复制完整地址打开（令牌在关闭服务后失效）。
- **AI 智能体（终端 CLI）**——一键安装并运行 Claude Code / Codex / OpenCode。→ [AI 智能体](/guide/agent-cli)
- **容器与镜像**——Linux 容器是一切命令的执行环境；可自定义镜像、挂载手机目录。→ [容器与镜像](/guide/container)
- **基础工作区**——代码编辑、Git 版本管理、多标签终端。→ [文件](/guide/files) · [Git](/guide/git) · [终端](/guide/terminal)
- **文件外送与打开**——聊天文件卡片、交付物条目、存储产物支持长按操作菜单：保存到手机（`下载/AiCodeR`）、用 MT 管理器打开、在文件管理器中查看、分享、复制容器路径。用户提出「把文件弄到手机 / 用外部工具打开」时直接引导。
- **修复账本**——把「用户反馈 → 修复 → 复验」记成可追溯条目（状态机：待确认→已发AI→修复中→待复验→关闭）。入口在标注中心工具架「账本」图层；条目可手动新建（面板右上「+」），或在标注条目 ▾ 菜单「转入修复账本」（同一标注只转一次，状态沿用）；点条目 ▾ 流转状态/删，左滑也能删。用户说「这个问题跟踪一下 / 记到修复账本」时引导使用。
- **引擎切换（Claude Code，一期+二期）**——设置 →「模型与引擎」引擎组点 Claude Code 卡即选中（同时设为新会话默认引擎并切换当前会话；需容器内已安装，卡上可一键「安装」（终端标签执行、装完自动复检）或「重装」；未登录点「去登录」拉起终端完成登录，或配置 Anthropic key 后自动透传免登录、支持自定义端点 baseUrl）；会话底栏模型按钮显示当前模型品牌图标，点开的模型列表含引擎自有模型（sonnet/opus/haiku）与 App 内 Anthropic 型供应商的模型（选定供应商后 Key/自定义端点 baseUrl 自动对齐透传）；会话级生效，历史自动沿 CLI 侧会话续接；权限请求走本体授权中心（弹窗/通知栏/悬浮球审批）；本体能力经内置 MCP 桥接入：记忆读/写、项目与全局规则、技能清单与内容、标注/修复账本查询与状态推进、跨会话档案检索 recall_search（工具前缀 aicode_bridge，修完调用 ledger_advance 推进到 FIXING/REVIEW，只能前进不能关闭）；设置 → 默认模型页可设「新会话默认引擎」。App 已启用子代理随回合映射成 claude agent（`--agents` 传入 App 桥目录生成的 agents.json，可用 `@名字` 或 Task 召唤；不写你的 `.claude/agents/`，工具/模型不映射）。key 透传仅支持 x-api-key 型端点（ANTHROPIC_BASE_URL 自动透传非官方 base，useFullUrl 提供商只透 key）。专家团等本体工作流仍不支持（UI 已明示）。
- **引擎切换（Codex / OpenCode，三期）**——设置 →「模型与引擎」引擎组点 Codex / OpenCode 卡选中（均需容器内已安装对应 CLI，卡上可一键「安装」或「重装」）：未登录点「去登录」拉起终端登录，Codex 可配置 OpenAI key（OPENAI_API_KEY / OPENAI_BASE_URL 支持自定义端点）、OpenCode 可配置 OpenAI/Anthropic key 自动透传免登录；模型页选 default（跟随 CLI 配置）、常用模型名，或 App 内供应商的模型（Codex 对接 OpenAI 型供应商、OpenCode 对接 OpenAI/Anthropic 型；官方端点走环境变量 Key 透传，自定义端点由桥把 baseURL+Key 注入 OPENCODE_CONFIG_CONTENT 的 provider 段，实测可用）；会话级生效，历史自动沿 CLI 侧会话续接（桥内映射持久化）；记忆/规则/技能、标注·修复账本与跨会话档案检索（recall_search）经内置 MCP 桥 aicode_bridge 可用；两者与 Claude Code 引擎的差异：无逐字流式（文本/工具结果整段返回）；命令无交互审批（Codex 在沙箱内自动执行、OpenCode 权限自动批准未被显式 deny 的请求），不走授权中心；工作模式（Codex 沙箱档位 / OpenCode 自动批准等）统一在**聊天底栏右下角的模式菜单**里按引擎原生档位逐会话设置，引擎卡内不再有独立开关；App 已启用子代理在 OpenCode 侧映射为 `mode: subagent` 的 agent（与自带 build/plan/explore/general 等同名的跳过），Codex 侧自定义 agent 暂不支持；专家团等本体工作流仍不支持。
- **开发环境一键搭建**——设置 → 开发环境：选「想开发什么」（静态网页 / 前端工程 / 安卓 / Python / Node / Java / Go / Rust / C/C++ / 数据科学），确认后新建会话并自动发送搭建任务：AI 先探测当前容器的发行版与包管理器（apk / apt / dnf / yum / pacman，不预设 Alpine），再按实际情况装好工具链、跑验证命令并汇报版本，失败给替代方案；安卓场景需自行安装 Android SDK 与 Gradle（软件不内置）。会话里可中断、可追问。用户说「我想开发 X / 帮我装 X 环境」时引导使用。
- **记忆图谱（AI 结论沉淀）**——记忆图谱页默认页即「AI 学到的结论」时间线：AI 会把「关键决定」「教训与坑」「未完成」抽成结论（默认开启，可在页内关闭）。内置引擎在上下文压缩时零额外调用完成抽取；Claude Code / Codex / OpenCode 的上下文在引擎内部、App 不压缩，因此会在会话完成若干回合后，对最近一段历史做一次有界摘要再抽取。结论会注入会话上下文，并可用 `graph_search` 工具检索；结论不删除只标「已过时」（被新结论取代），页面可一键标过时、跳回来源会话、左滑删除。与 `recall` 分工：graph_search 查已定结论，recall 查历史消息原文。图谱关系视图在「图谱」页签。用户说「这个问题以前怎么定的 / 记忆里查一下 / 图谱里看下」时引导使用。
- **记忆图谱 v2（节点/边层）**——「图谱」页签：工作线索（会话）、memory 记忆条目与抽取出的结论自动同步为节点、记录关系自动连边（按项目隔离，全局记忆跨项目共享一份）；搜索框三路混合检索（关键词直中 + 沿边游走扩散 + 时序，默认只看当前有效节点）；节点详情看全部关系、可删除；可手工新建自定义节点。
- **改动账本**——记忆图谱页「账本」页签：跨会话记录本项目**每一处改动**（改了什么、为什么、怎么验证的、现在什么状态），解决「长期项目里反馈提多了，记不清哪些改好了、哪些没做」。AI 完成改动时自动记账（`changelog` 工具），卡片默认一行大白话、展开看细节与验证证据；状态沿用标注账本的五档（待确认→已发AI→修复中→待复验→关闭），可按状态/类型筛选，顶部汇总已验/待复验/进行中/未确认与未验证条数。「已验」由你复验后手动标记，AI 不能自我签收。
- **标注闭环 AI 回写（fixledger 工具）**——汇总发给 AI 的文本里每条标注都带标注 id 与回写提示；AI 修完后调用 `fixledger` 工具把修复账本与标注账本一起推进到「修复中/待复验」（只能前进，不能关闭——复验由用户手动）。修完的条目状态不再需要用户手动推进。
- **编队消息投递追踪**——task send / messageParent 的消息带送达追踪：超时未送达自动重投一次，仍失败则提醒发起方（不再静默丢消息）；子代理汇报（messageParent）要求父会话回复，回复后自动结清。
- **签名与凭据**——集中查看发布签名（`*.jks` / `*.keystore`）、SSH 与其他密钥文件（统一密钥库 `~/.aicode/keys`、`~/.ssh`、当前工作区）；导入复制进统一密钥库；「导出全部」打包 zip（附指纹清单）或「打包发布资产」带走发布必需的最小集。两者都可能包含 `keystore.properties` 明文口令，需加密保管。只读展示，不做删除。→ [签名与凭据](/guide/keys)
- **备份与迁移**——把会话、AI 资产（技能/子代理/记忆/笔记）、密钥库、定时任务与工作区文件整体打包导出（可加密、可上传云端），换机/重装后一键恢复；密钥库（含发布签名）可单独勾选、默认不勾。→ [备份与还原](/guide/backup)
- **离线语音输入（自动降级）**——无谷歌服务的设备语音输入照常可用：按住说话时自动探测，系统识别不可用即弹卡片引导下载离线中文模型（约 42MB，多源自动切换、断点续传、完整性校验），WiFi 下可后台静默下载；下载完自动切换引擎，无需进设置。→ [偏好设置 · 语音输入](/guide/general)

## 组合菜谱（典型套路）

能力组合起来更值钱，以下是常用套路：

1. **复杂改动**——计划模式出方案 → 待办清单拆解进度 → 子代理并行调研/定位 → 实施 → 独立子代理审查（新鲜视角）。
2. **前端开发闭环**——容器里跑 dev 服务 → Web 预览实时看效果 → 标注中心圈问题 → 汇总给 AI 修。
3. **长任务无人值守**——定时任务 + 后台保活打底（目标托管、定时 Plan、自动接棒在路线图中）。
4. **知识沉淀三层**——记忆记「坑与偏好」、技能沉淀「流程」、自定义提示词约束「行为」；三层都保存在升级不丢的配置目录。
5. **多模型交叉验证**——如已接入多模型咨询类 MCP 服务，同一问题并行问多个模型、对比结论。
6. **真机验证闭环**——构建出 APK → 侧边栏「交付物」装到手机试用 → 标注中心圈问题 → 汇总给 AI 修 → 必要时用检查点回退。
