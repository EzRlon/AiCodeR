# 能力地图（场景速查）

许愿码里的 AI 不只是「会读写文件和跑命令」——它还能调动一批软件能力：规划与拆解、分身协作、知识沉淀、定时执行、界面验证、设备操作等。本页把软件能力按「场景 → 能力」整理成一张地图。

AI 在任务中会对照本页选择与组合能力；你也可以用它了解许愿码能帮你做什么。

## 一、开发与协作

- **三种模式（Build / Plan / Auto）**——Build 直接执行；Plan 只读规划、先出方案；Auto 自动放行、全速推进。AI 在需要规划时会申请进入计划模式，你在输入区模式图标里切换。→ [三种模式](/guide/modes)
- **子代理**——派生独立小助手并行干活：代码库调研、批量定位、独立审查，主对话只收结论摘要。AI 用 `task` 派发；你可在设置中自定义角色、模型与工具范围。→ [子代理](/guide/subagent)
- **专家团（专家团）**——给会话挂上一组角色（如产品 + 架构 + 前端 + 质检），一键进入专家团协作。聊天页顶栏入口召唤。
- **检查点与撤销**——AI 每次改文件前自动快照。改动不满意时，「这一轮重来」（代码与对话一起回退），或只回退其一。→ [检查点与撤销](/guide/checkpoint)
- **消息类型**——发送前给消息打一个类型标签（缺陷修复 / 方案计划 / 调研研究……），AI 据此调整处理策略。输入区细标签行选择，发送后自动重置。
- **交接提醒与自动交接**——对话上下文过半时，回合结束会提示建议 `/compress` 压缩或开新会话接手（默认 50%，每会话最多两次）；正常情况下自动压缩会先接管（默认 70%），自动交接退化为兑底：默认达到 93% 才暂停当前会话、生成接手摘要并直接开新会话接力（交接会带上目标/模式/专家团；设置 → 偏好设置可开关自动交接与调整阈值）。
- **会话目标（Goal）**——输入 `/goal <目标>` 后 AI 围绕目标自主循环推进：自动连续工作、用证据审计完成度，达成或受阻才停（`/goal pause` 暂停、`/goal resume` 续跑、`/goal clear` 清除）；轮次与 token 预算可在设置 → 偏好设置调整。→ [会话目标](/guide/goal)
- **悬浮球（精灵球）**——设置 → 偏好设置开启后，切到其它 App 时仍有一个可拖动的精灵球：待机只露一枚贴边小胶囊，颜色即状态（绿=进行中带 600ms 透明度呼吸/红=失败/灰=空闲）；点击展开为圆球（中央显示待办完成数字或闪电图标，外圈进度弧）并弹面板：看待办进度与回复预览、对工具授权请求直接允许/拒绝、快速输入发送到当前会话、停止任务、一键回到 App；拖拽松手自动吸附就近边并缩回待机胶囊（需「显示在其他应用上层」权限；不读屏、不模拟操作）。
- **交付物页**——左侧栏「交付物」页跨会话聚合 AI 产出的安装包与文件（会话附件 + 工作区 APK），按后缀类型分组、组内时间倒序；点行可安装/打开、用 MT 管理器或文件管理器打开、保存到手机、分享、复制路径。
- **审批通知直达与实时进度**——设置 → 后台运行可开启：AI 在后台等审批/回答时弹通知、通知栏直接批准或拒绝；AI 工作中有常驻实时进度通知（Android 16 支持提升到状态栏）。
- **自我改进模式**——开启后 AI 会反思表现，把改进沉淀为技能或提示词片段（保存在升级不丢的配置目录）。→ 设置 → 偏好设置

## 二、知识与沉淀

- **自动记忆**——AI 主动记录用户偏好、项目约定与踩坑经验，跨会话生效；分全局与项目两级，可查看与增删。→ [记忆与项目规则](/guide/memory)
- **技能**——把一类任务的标准流程与知识写成「专项能力包」，AI 遇到相关任务自动按需加载。→ [技能](/guide/skills)
- **省 Token 内置技能**——`token-saver`（输出过滤、精确读取、子代理带回摘要等操作纪律）与 `context-compression`（压缩时机、应固化的信息、与交接配合）随 App 内置、升级自动更新；AI 遇到相关任务自动按需加载，也可用 `/技能名` 手动触发。→ [技能](/guide/skills)
- **在线商店**——在设置里浏览并安装社区技能（claudemarket.ai）、MCP 服务器（官方 Registry）与内置专家团（成套团队：软件开发/产品设计/美工设计/调研等，一键装入团队与成员角色）：搜索/分页/一键安装；点任意条目弹详情（中英名称与描述对照、meta、来源链接、安装按钮）；「安装 ≠ 启用」，装完默认不生效，确认后再启用；专家团装好后在聊天页「召唤专家团」使用。→ 设置 → 在线商店
- **子代理独立模型**——设置 → 默认模型 → 智能体模型：主代理与每个子代理（内置专家/自定义角色）可分别选模型或「跟随主代理」；自定义角色定义里显式配置的模型优先于设置页覆盖。
- **自定义提示词**——覆盖或新增系统提示词片段，精确调整 AI 的行为规则。→ [自定义提示词](/guide/custom-prompts)
- **笔记模式**——Markdown 文件可在编辑器里切换所见即所得模式，像记笔记一样整理文档。
- **记忆图谱**——把项目、会话与子代理画成一张可点选的图，快速回到某条工作线索。聊天页顶栏入口。

## 三、自动化与长任务

- **定时任务 / 定时 Plan**——到点自动执行：「定时任务」可执行一条容器命令（每天 / 间隔 / 仅一次），或给 AI 一条指令由它无人值守自主完成（预授权范围内自动放行、超范围等通知授权，10 分钟无人应答自动拒绝）；「定时 Plan（长任务）」先聊出完整计划、批准后从计划审批面板排期，到点在新会话中无人值守自主施工（单次上限 12 小时）。入口：长按会话输入区的模式图标（Build → 定时任务；Plan → 定时 Plan），或长按顶栏「+」；排期与启停在设置 → 定时任务管理。→ 设置 → 定时任务
- **后台运行保活**——AI 执行任务期间自动保活防止中断；也可手动开启「空闲常驻」，让终端里自行运行的长命令不被系统回收。→ [后台运行](/guide/background-run)
- **工具钩子（Hooks）**——AI 每次调用工具前后自动运行你写的脚本：静态检查、拦截危险操作、补充上下文。→ [工具钩子](/guide/hooks)

## 四、界面与验证

- **界面标注（活标注）**——发现界面问题或想改的地方：直接在真实界面上标注（弹窗照弹、按钮照点；浮动工具条画形状/文字，选择工具可点中真实组件），「完成」时整屏定格一帧（含已打开的弹窗）进编辑器精修；不画任何标记直接「完成」即整屏截图，同一入口覆盖原截屏标注场景。按类型（bug / 要改 / 不要 / 优化）记进账本，最后一次性汇总发给 AI：汇总文本每条附结构化坐标区间（框选/箭头/直线/笔迹/文字的归一化百分比位置 + 附注），AI 无需只靠看图猜位置。→ [界面标注](/guide/annotations)
- **Web 预览**——容器里跑的前端服务直接在内嵌浏览器打开，改完即刷；大屏下与聊天并排。→ [Web 预览](/guide/preview)
- **VNC 悬浮窗**——把容器图形画面悬浮在聊天上方；AI 启动图形程序时自动弹出，可实时看它操作。→ [VNC 悬浮窗](/guide/vnc)
- **测试包与一键安装**——工作区里构建出的 APK 集中列出，点一下装到手机。→ [测试包与一键安装](/guide/test-builds)
- **通知栏批准**——AI 请求工具授权时，可直接从通知栏批准或拒绝，不必切回 App。→ [工具授权](/guide/permissions)
- **工具授权中心**——给每个工具设置权限档位（自动允许 / 每次询问 / 禁止），预置「日常 / 离开模式 / 只读演示」档案一键套用；授权记录里可回看每次批准与拒绝。→ [工具授权](/guide/permissions)
- **守夜守护（无人值守）**——离开/睡觉时让 AI 继续推进：危险操作自动拒绝并给出改写引导、弹窗超时自动拒绝、计划审查自动通过，不无限等待；授权记录可回看被拒动作。设置 → 工具授权 → 守夜守护。（**1.13.0 起**）

## 五、外部与设备

- **MCP 服务器**——接入外部工具能力：浏览器自动化、多模型并行咨询、专用服务等；添加面板「推荐」区内置 Context7（最新库/框架文档检索，远程 HTTP 零安装、默认不启用）可一键添加。→ [MCP 服务器](/guide/mcp)
- **REA 逆向分析**——分析没有源码的成品软件（App / APK / JS-Electron 包 / 归档包等）是怎么实现的：解释功能原理、定位实现代码、复刻某功能；结论带证据与局限。用法：侧栏「逆向分析」工作台一键「安装环境」+「一键接入」（自动装引擎、加白名单预设；工作台自带：环境三态判定与动作引导、MCP 真连接状态（失败显原因可重连）、分析目标扫描（自动列工作区 APK/DEX/JAR/SO/JS 等样本，按修改时间排序）、学习任务模板、可用工具清单与 node/java/jadx 组件实测；终端 `aicode` 选「逆向分析」场景、设置 → MCP → 推荐区添加「REA 逆向工程」为同效入口）；之后对话即可（如「帮我分析这个 APK 的登录流程」）。仅限你拥有或获授权分析的软件。→ [逆向分析](/guide/reverse-engineering)
- **内置浏览器**——AI 可后台自动操作网页并截图；你也可以自己浏览（书签、历史、多标签）。→ [内置浏览器](/guide/browser)
- **联网检索**——AI 按需搜索与抓取网页资料（websearch / webfetch）。
- **Shizuku**——用户授权后，AI 可在宿主 Android 系统上执行命令（ADB 级）；每次调用弹窗确认。→ [Shizuku 工具](/guide/shizuku)
- **远程 SSH**——执行环境可放到远程服务器，工作区文件读写经由 SSH 完成。→ [远程 SSH](/guide/remote-ssh)
- **工作区同步与内置 FTP**——把工作区同步到 SFTP/FTP 服务器；也可在手机上开 FTP 服务，用电脑管理 `projects/` 下的项目文件。→ [工作区同步](/guide/sync)
- **远程管理**——局域网网页服务：用电脑浏览器浏览、上传、下载、重命名和删除手机外部存储里的文件。
- **AI 智能体（终端 CLI）**——一键安装并运行 Claude Code / Codex / OpenCode。→ [AI 智能体](/guide/agent-cli)
- **容器与镜像**——Linux 容器是一切命令的执行环境；可自定义镜像、挂载手机目录。→ [容器与镜像](/guide/container)
- **基础工作区**——代码编辑、Git 版本管理、多标签终端。→ [文件](/guide/files) · [Git](/guide/git) · [终端](/guide/terminal)
- **文件外送与打开**——聊天文件卡片、测试包、存储产物支持长按操作菜单：保存到手机（`下载/AiCodeR`）、用 MT 管理器打开、在文件管理器中查看、分享、复制容器路径。用户提出「把文件弄到手机 / 用外部工具打开」时直接引导。
- **密钥管理**——集中查看发布签名（`*.jks` / `*.keystore`）、SSH 与其他密钥文件（统一密钥库 `~/.aicode/keys`、`~/.ssh`、当前工作区）；导入复制进统一密钥库、导出打包 zip（附指纹清单，不含密码）。只读展示，不做删除。→ [密钥管理](/guide/keys)
- **备份与迁移**——把会话、AI 资产（技能/子代理/记忆/笔记）、密钥库、定时任务与工作区文件整体打包导出（可加密、可上传云端），换机/重装后一键恢复；密钥库（含发布签名）可单独勾选、默认不勾。→ [备份与还原](/guide/backup)
- **离线语音输入（自动降级）**——无谷歌服务的设备语音输入照常可用：按住说话时自动探测，系统识别不可用即弹卡片引导下载离线中文模型（约 42MB，多源自动切换、断点续传、完整性校验），WiFi 下可后台静默下载；下载完自动切换引擎，无需进设置。→ [偏好设置 · 语音输入](/guide/general)

## 组合菜谱（典型套路）

能力组合起来更值钱，以下是常用套路：

1. **复杂改动**——计划模式出方案 → 待办清单拆解进度 → 子代理并行调研/定位 → 实施 → 独立子代理审查（新鲜视角）。
2. **前端开发闭环**——容器里跑 dev 服务 → Web 预览实时看效果 → 界面标注圈问题 → 汇总给 AI 修。
3. **长任务无人值守**——定时任务 + 后台保活打底（目标托管、定时 Plan、自动接棒在路线图中）。
4. **知识沉淀三层**——记忆记「坑与偏好」、技能沉淀「流程」、自定义提示词约束「行为」；三层都保存在升级不丢的配置目录。
5. **多模型交叉验证**——如已接入多模型咨询类 MCP 服务，同一问题并行问多个模型、对比结论。
6. **真机验证闭环**——构建出 APK → 侧边栏「测试包」装到手机试用 → 界面标注圈问题 → 汇总给 AI 修 → 必要时用检查点回退。

## 维护说明

本页同时充当 AI 的「能力索引」：系统提示词里有一份精简的场景速查指向本页，AI 在任务中会对照它选择与组合能力。因此——新增功能上线时，必须同步更新本页与速查片段；判断某项能力是否在当前版本可用，以本页为准。

收录口径：与 AI 协作或功能发现相关的能力（纯界面与系统维护类功能见[功能总览](/guide/overview)）；规划中的能力不入图，上线后再登记。
