# 标注中心（统一画布）

发现界面上的问题或想调整的地方时，在侧栏打开「标注中心」：进来就是**一块画布 + 一条工具架**，捕捉、标注、账本管理全流程在同一界面完成，最后一次性汇总发给 AI 处理。整个流程在软件内完成，不需要任何系统权限。

## 工具架

画布上方悬浮一条工具架（可拖动、记住位置），两行按钮：

- **第一行**：颜色圆点（bug / 要改 / 不要 / 优化 四色循环，按钮底色即当前标注色）、矩形、直线、箭头、自由笔、文字；未定格时另有「选择」工具。
- **第二行**：定格截屏、撤销、重做、清空、账本、保存入账本、退出。

## 两种画法（同一块画布）

1. **直接在真实界面上圈画（未定格）**：画布透明叠在当前界面上，未选工具时触摸全部穿透——弹窗照弹、按钮照点（想标注弹窗就先点开弹窗）。选好工具即可直接画。「选择」工具可点已画标注整体拖动（文字可再编辑），点界面上的真实组件会虚线框住，可「在此处加文字」或「从这里画箭头」。
2. **定格后精画**：点「定格截屏」，系统询问屏幕捕获授权（每次确认一次），画布先隐藏再抓一帧整屏（**包含已打开的弹窗**）作为底图，已画的标注原样保留；之后在底图上精画，支持**双指缩放平移**细看局部。再点「定格」可随时换新底图（已画标注保留，账本条目的编辑上下文会清空）。

## 保存入账本

点「保存入账本」：选择标注类型（四色徽章）+ 可选补充说明，确认后写入账本；画布保留，可继续画下一条（一张底图可出多条账目）。未定格时保存会提示先定格。

## 账本图层（标注 + 修复账本合流）

点工具架「账本」，右侧滑出账本面板：

- **标注条目**：类型色点 + 说明 + 状态徽章 + 时间；**点行 = 载入画布重绘**，可继续补画后保存为更新（不重拍图）；▾ 菜单可流转状态（待确认 → 已发AI → 修复中 → 待复验 → 关闭）、转入修复账本、删除；左滑也能删。
- **修复账本条目**：标题 + 备注 + 状态徽章；▾ 菜单流转状态或删除；左滑删除；面板右上「+」手动新建（摘要必填、备注可选）。

## 汇总发给 AI

面板右上「汇总发给 AI」：把所有**未关闭**的标注生成一段结构化描述注入聊天输入框，图片同时作为待发附件准备好——回到聊天页确认后直接发送即可。AI 会按类型处理：bug=修复；要改=按说明调整；不要=避免图中的做法；优化=酌情改进。修完后 AI 会调用 `fixledger` 工具把对应条目推进到「修复中 / 待复验」。

## 文件位置

截图保存在当前工作区的 `.aicode/annotations/` 目录下，随工作区走、可被 AI 直接读取；对应的元数据（类型/状态/说明）存在 App 本地数据库。删除账目时一并删除对应截图。

## 已知限制

- 平板/横屏（大屏布局）下常驻侧栏不会收起，定格图会包含侧栏区域；手机竖屏下侧栏会先收起再定格。
- 定格新底图时已画标注保留，但账本条目的编辑上下文（更新目标）会清空（账本里已保存的不受影响）。
