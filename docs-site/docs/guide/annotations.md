# 界面标注（截图标注账本）

发现界面上的问题或想调整的地方时，直接在界面上标注或截屏圈画、记进账本，最后一次性汇总发给 AI 处理。整个流程在软件内完成，不需要任何系统权限。

## 界面标注（活标注）

在**真实界面**上直接标注，「弹窗照弹、按钮照点」，所见即所得：

1. 打开聊天页左侧边栏，点「界面标注」。
2. 侧栏收起后进入标注层：界面照常可操作（想标注弹窗就先点开弹窗）。
3. 拖动浮动工具条到顺手的位置：先点颜色圆点选标注色（bug / 要改 / 不要 / 优化 四色循环），再点工具（矩形 / 直线 / 箭头 / 自由笔 / 文字）在界面上画。
4. 「选择」工具：点已画的标注可整体拖动（文字可再编辑内容）；点界面上的真实组件会虚线框住，可「在此处加文字」或「从这里画箭头」。
5. 点「✓ 完成」：系统询问屏幕捕获授权（每次确认一次），定格一帧整屏画面（**包含已打开的弹窗**）并带上你的标注进入编辑页，可继续精修后保存入账本。

## 截屏标注

1. 打开聊天页左侧边栏，点「截屏标注」。
2. 侧栏收起后自动截取当前界面，进入标注编辑页。
3. 顶部选择标注类型（四种，按钮颜色即标注颜色）：
   - **bug**：这里有 bug / 问题，需要修复
   - **要改**：这里要改成期望的行为或样式
   - **不要**：不要按图里的做法来
   - **优化**：这里可以优化
4. 在图上圈画：默认「矩形框」，点笔形按钮切换为「自由笔」；画错了点垃圾桶撤销上一笔。
5. 可在底部填一句补充说明（可选），点「保存」收入账本。

一张截图可以画多笔标注（每笔用当前选中的类型色）。

## 标注账本

侧边栏「标注账本」查看全部记录：

- 每行显示类型色点、说明、状态与时间；**左滑删除**。
- 点开任意一条可看大图（标注按原样重绘），并在右上角的状态胶囊处**流转状态**：待确认 → 已发AI → 修复中 → 待复验 → 关闭（可点任意状态直接切换）。

## 汇总发给 AI

账本页右上角「汇总发给 AI」：把所有**未关闭**的标注生成一段结构化描述注入聊天输入框，图片同时作为待发附件准备好——回到聊天页确认后直接发送即可。AI 会按类型处理：bug=修复；要改=按说明调整；不要=避免图中的做法；优化=酌情改进。

## 文件位置

截图保存在当前工作区的 `.aicode/annotations/` 目录下，随工作区走、可被 AI 直接读取；对应的元数据（类型/状态/说明）存在 App 本地数据库。删除账目时一并删除对应截图。

## 已知限制

- 平板/横屏（大屏布局）下常驻侧栏不会收起，截图会包含侧栏区域；手机竖屏下侧栏会先收起再截图。
