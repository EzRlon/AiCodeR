# Token 统计与费用

「设置 → Token 统计」记录每一次 AI 调用的消耗，用于查看 token 用量、费用、缓存命中情况与估算输出速率。

页面分为「概览」「请求日志」「分析」三个视图，顶部周期与供应商/模型筛选在各视图间共用。数据从该功能上线后开始记录，已有历史调用不会补造缺失的计时数据。页面实时刷新。

## 周期切换与维度筛选

顶部四个标签：今天 / 近 7 天 / 近 30 天 / 全部。切换后下面所有卡片、图表和列表同步更新。「今天」的趋势图按小时展示，其余按天。

周期下方提供维度筛选条：
- **供应商筛选**：下拉选择「全部供应商」或指定供应商。
- **模型筛选**：下拉选择「全部模型」或指定模型。
- **清除筛选**：激活筛选后出现，点击可一键重置为全部数据。
- 此外，直接点击「供应商统计」或「模型统计」中的任意一行，也可快速将该项设为筛选条件，再次点击即可取消。

## 概览

一张概览卡集中展示：**总消耗**（输入加输出）、**费用**、**token 构成条**和关键指标标签（调用次数、成功率、缓存命中率）。

构成条把一次周期的 token 分成四段，颜色与下方图例对应：

| 分段 | 含义 |
| --- | --- |
| 新增输入 | 未命中缓存、真正发送给模型的新内容 |
| 缓存读取 | 命中服务端提示缓存的上下文（通常占比最大） |
| 缓存写入 | 写入服务端缓存的 token（部分供应商才有） |
| 输出 | 模型生成的内容（含思考 token，按各供应商口径） |

**总消耗包含缓存读取与写入**，缓存是它的子集，不会再额外加一遍。因此「总消耗」衡量的是模型处理过的全部上下文，而不是「新增」了多少内容；看真实增量请看「新增输入」。Claude Code / Codex / OpenCode 外部引擎的调用也会记录进来，渠道标签会标明「引擎桥接」。

费用是**估算值**，优先使用你在「供应商 → 模型」里填的自定义单价，未填的才按 models.dev 的公开单价计算：缓存读取按缓存价计算，没有缓存价时按输入价的 10% 估；缓存写入按缓存写入价计算，没有时按输入价的 1.25 倍估。总费用按「渠道 + 模型」分别套单价再求和，因此同一个模型从不同供应商调用会各自计价。

::: tip 费用仅供参考
这是按公开单价估算的结果，不是账单。中转站改过价格、有折扣，或你使用的模型没有单价数据时，估算会和实际扣费不一致。以供应商后台的账单为准。
:::

## 消耗趋势

折线图展示周期内三条**互不重叠**的线：新增输入（蓝）、缓存读取（紫）、输出（橙）。缓存是输入的子集，分成独立曲线后不会出现「两条线重叠误导」的问题。左轴是 token 数（用 k / M 缩写）。

时间轴按周期完整展开，没有记录的天或小时补 0，因此调用集中在某一天时也能正常看出走势。

## 渠道与模型统计

**渠道统计**按供应商聚合：名称旁有「内置引擎 / 引擎桥接」分类标签，下面是密钥数、成功率、缓存命中率标签，以及一条 token 构成条；右侧突出请求次数。按总消耗倒序排列。

**模型统计**按模型聚合，每行显示模型名、调用次数 / 成功率 / 缓存命中率标签和构成条，按总消耗倒序排列。

点击任意渠道或模型行可快速作为筛选条件联动整页数据。

## 调用记录

每页 10 条的可展开卡片。默认一行显示最常看的信息：状态点、时间、渠道标签、费用、模型名，以及「↑新增输入 / ⚡缓存命中率 / ↓输出 / 耗时」。

点击任意一行展开详情：

| 字段 | 说明 |
| --- | --- |
| 缓存读取 / 缓存写入 | 本次命中与写入缓存的 token 数 |
| 首字延迟 | 从请求发出到首个内容事件（文本、思考或工具调用结果）到达的时间 |
| 总耗时 | 本次调用的总时长 |
| 思考强度 | 本次调用的档位，没有档位的模型显示 `-`；实际发出的档位与所选不同时显示 `所选→实发`（如 `max→high`），并在下方标出「思考档位已降级」 |
| 重试 | 底层网络重试次数 |
| 失败原因 | 仅失败调用显示 |

纯工具调用的那一轮也会统计首字延迟。

**为什么会出现「降级」**：不同模型支持的思考档位不同，某些档位还会被服务端拒绝。App 会把你要的档位向下调整到模型真正接受的档位再发出——以前这种调整是静默的，现在会记在记录里，好让你知道「选了 high 却像没思考」到底是设置没生效还是被降级了。

**关于「记住被拒档位」**：当某档位被服务端拒绝时，App 会记住「这个渠道的这个模型不吃这一档」，下次直接避开，省得每次都撞一次错。这份记忆按渠道与模型分别保存，并有三重保护，任何一次误判都不会长期生效：模型元数据（官方档位列表）始终优先，记忆只用来进一步收窄、不会反过来推翻元数据；每条记忆两小时后自动过期；只要某档位调用成功了，它就会被立刻解除标记。你无需手动清理。

## 重置

页面右上角的垃圾桶图标可以清空全部调用记录，统计随之归零。会弹确认框，**清空后不可恢复**。
