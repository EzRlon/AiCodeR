# 交付物与一键安装

AI 在会话里交给你的东西——构建出的安装包、生成的文件、截图等——都汇总在左侧边栏的「交付物」页。它是把文件拿到手机、把 APK 装到本机的主要入口。

## 交付物页能看到什么

- **跨会话聚合**：AI 通过会话附件交给你的文件（安装包 `.apk`/`.apks`/`.xapk`、文档、图片、压缩包等），按当前工作区过滤，不混入别的项目。
- **按类型分组**：同一后缀的排在一起，组内按时间从新到旧。
- **每行显示**：文件名、大小、时间与来源会话，点开可回到对应会话看上下文。

## 能做什么

点一行展开操作，或长按直接弹菜单：

| 操作 | 说明 |
| --- | --- |
| 安装（APK） | 唤起系统安装器装到本机；未授权「安装未知应用」时先引导开启 |
| 打开 | 用系统关联应用打开（图片、文档等） |
| 用 MT 管理器 / 文件管理器打开 | 交给外部工具处理 |
| 分享 | 走系统分享面板发给其它 App |
| 复制路径 | 复制容器内的完整路径，便于在终端/其它工具里引用 |
| 仅从列表移除 | 只去掉这条记录，容器里的文件保留 |
| 彻底删除 | 连带删除容器/工作区文件与已导出的真机副本，需二次确认 |

## 文件什么时候才到手机

交付物**不会预先占用手机空间**：只有在你真正点「打开 / 分享 / 安装」时，才按需把文件导出到手机「下载/AiCodeR」目录。列表里的路径是容器内路径。

## 说明

- 新构建的产物没出现时，点右上角刷新重新聚合。
- 「彻底删除」会同时清掉容器内文件，且不可撤销——只想去掉列表记录时用「仅从列表移除」。
