# Web 预览

在容器里跑起的前端开发服务（`npm run dev`、`vite`、Python `http.server` 等），可以直接在 AiCode 内嵌浏览器里打开预览——手机与容器共享网络，页面即改即刷新（热更新由页面自身完成）。

## 使用

1. 在终端里启动你的开发服务（也可以让 AI 帮你起，例如「在容器里跑 npm run dev」）。
2. 打开左侧边栏 →「Web 预览」。
3. 输入服务的端口号（`:3000` `:5173` `:8080` 三个常见端口有快捷按钮），点「打开」。
4. 页面加载后即可交互；改了代码后前端热更新会自动生效，也可以点刷新按钮手动重载。

## 大屏体验

平板/横屏下，「Web 预览」会占用右侧工作台分栏，与聊天并排——左边让 AI 改代码，右边实时看效果。

## 常见问题

- **连不上 127.0.0.1:端口**：确认服务已在容器里启动且监听该端口；服务绑定地址需要能接受本机访问（一般默认即可）。
- **服务怎么起**：在终端执行启动命令即可，例如 `cd ~/workspace/你的项目 && npm install && npm run dev`。
