# 标注中心「统一画布」设计稿（反馈 6 定稿，待实现）

> 用户要求（原话核心）：进标注中心后**只有一套工具架**，融为一个界面；不再是「点一个按钮进入旧功能界面」。当前四模块（活标注/截屏标注/账本/修复账本）拆散的状态不合格。

## 目标形态

进入「标注中心」= 一块画布 + 一条工具栏，全流程同界面完成：

1. **画布区（主区）**：
   - 默认态 = 上次截屏帧或占位引导；顶部工具架点「定格」走 MediaProjection 抓当前屏（含弹窗）作为底图；
   - 底图之上直接绘制（活标注与截屏标注合一，消掉两套坐标上下文）：画笔/直线/箭头/矩形/文字/撤销/重做/清空；
   - 画布可缩放平移（双指），标注坐标仍以归一化存储（AnnotationMarksCodec 不变）。
2. **工具架（一条，画布上方悬浮）**：定格截屏 | 画笔 | 文字 | 撤销 | 清空 | 保存入账本。
3. **账本图层（同界面，右侧滑出或底部列表切换）**：
   - 账本条目列表（标注+修复账本合流展示，条目带状态徽章）；
   - 点条目 = 在画布上重绘该条标注（可继续补画后保存为更新，复用 saveCapture 的 update 路径或新增 updateMarks）；
   - 「汇总发给 AI」「转入修复账本」「AI 回写状态」逻辑保留（fixledger 工具不动）。
4. **禁止**：任何「点按钮 → 跳转旧 AnnotationEditorDialog 全屏 / 旧 Hub 列表页」的路径。

## 实现要点

- 复用：AnnotationEditorDialog 的 drawMark/FitRect/手势逻辑下沉为共享绘制层（AnnotationCanvas composable）；LiveAnnotationOverlay 的触摸穿透与 MediaProjection 抓帧复用；
- Repository 层不动（annotations/fix_ledger 两表与状态机不变）；变的是 UI 层合一；
- 迁移无（无 schema 变更）；能力登记更新。

## 分批

- 批 1：画布合一（绘制层共享 + 工具架 + 定格即画）；
- 批 2：账本图层化（同界面列表 + 条目重绘补画）；
- 批 3：收尾（删除旧 Dialog/Hub 独立入口，保留组件供复用）。
