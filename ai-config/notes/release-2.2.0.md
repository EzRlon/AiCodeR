## 正式版 v2.2.0（versionCode 203）

相对 v2.1.0（versionCode 93）共 108 个提交，集中在三件事：多引擎、无人值守、移动化工作流。

### 执行引擎

- **Claude Code / Codex / OpenCode 三引擎接入**：会话级切换，历史经引擎侧会话 id 持久映射自动续接，消息渲染 / 子代理 / 检查点 / 审批全链路不分引擎
- **权限桥**：Claude Code 侧用回环 TCP + 随机 token 把每次工具请求路由回授权中心，拒绝即回写 deny；token 与会话 id 分离
- **能力桥 aicode_bridge**：记忆读写、项目与全局规则、技能清单与正文、标注与修复账本流转、跨会话全文检索（`recall_search`）以 MCP 工具形式提供给三个引擎；零写用户 CLI 配置文件
- **App 侧资产向下映射**：已启用的子代理按回合映射为引擎 agent，用户自装 MCP 自动并入三引擎配置（OAuth 跳过）
- **供应商模型对接**：Codex 走 OpenAI 型、OpenCode 走 OpenAI/Anthropic 型供应商，自定义端点由桥注入 baseURL 与 Key；引擎卡提供沙箱档位（Codex）/ 自动批准（OpenCode）开关

### 上下文与协作

- **压缩保真**：微压缩从纯截断改为保留语义锚点（退出码、BUILD SUCCESSFUL/FAILED、error 行、Exception、测试计数），压缩后仍能判错；九段式摘要加「语义锚点必保留」硬规则；分档窗口按模型窗口自适应
- **失败埋点**：三类事件（意图纠正 / 任务失败 / 编译失败），60 秒去重、90 天清理，失败静默不影响主流程
- **模型探测与路由表**：启动 8 秒后静默探测已配置供应商（1 小时 TTL），按任务角色选档、失败逐级升级
- **记忆图谱 v2**：节点/边两层、多空间、会话与 memory 双源同步、三路混合检索
- **专家团**：`summon_team` 识别项目级诉求自动召唤；编队消息投递追踪（送达/回复状态机、超时重投）
- **子代理派发四件**：任务书模板库（`task(brief=)`）、任务期工具收敛（`task(tools=)`）、报告自动归档（子会话删除后仍可读回）、意图理解三层制（低/中/高模糊分别直接做 / 一句话复述 / 选项式澄清）
- **项目任务账本 + 项目知识库索引**

### 移动化工作流

- **标注中心统一画布**：活标注、截屏标注、修复账本合流到一块画布 + 一条工具架，侧栏单入口；标注转入修复账本，AI 用 `fixledger` 回写推进状态
- **悬浮窗底栏重构**：输入入口图标化置于模型/语音之间，点击向上展开输入窗；发送后自动收起；顶部钉住开关；气泡双色区分；一键回底（仅在已处底部时才自动滚底）
- **危险程度动态外框**：底栏外框按任务危险程度变色，不含进度语义
- **交付物页收紧**：只认 AI 发进会话的附件，去掉工作区 APK 盲扫
- **极黑（OLED）主题** + 首帧窗口底色同步，冷启动不闪色
- **返回键分层守护**、日志清除、`.md` 直接进编辑器

### 自动化与安全

- **用户脚本三切片**：`run_script` 工具与脚本仓库、设置页「脚本」分区、定时任务「运行脚本」动作
- **开发环境一键搭建**：10 类开发方向（静态网页/前端/安卓/Python/Node/Java/Go/Rust/C/C++/数据科学），确认后自动建会话并让 AI 装工具链、跑验证、报版本
- **能力下沉**：代码智能四件套（ctags 索引 + repo-map + callchain + ast-grep）与本地模型（llama.cpp）内置为容器场景
- **存储推荐清理**：三级判定 + 孤儿检测 + 禁区白名单，每周只扫不删
- **商店安装安全层**：本地规则扫描 + 挂起确认
- **会话回收站**：30 天软删可恢复
- **会话导入**：长按菜单导入单会话包，同 ID 覆盖恢复、同标题不同 ID 可选覆盖或另存
- **REA 工作台合规层**：首次知情告知书、常驻合规横幅、SAF 导入与样本删除

### 工程

- 数据库迁移 69–72：修复账本表、会话引擎列、记忆图谱节点/边表、失败事件
- 构建锁（防双会话并行污染 KSP 缓存）与正式包多维自检脚本
- detekt 工具链入库；能力地图与 AI 速查片段随功能同步

### 安装

- 真机（arm64）：下载 `aicode-arm64-v2.2.0.apk` 安装
- 或在 App 内：设置 → 关于 → 检查更新（自动检测本 Release）
- 与 v2.1.0 同一签名钥匙，可直接覆盖升级，数据保留
