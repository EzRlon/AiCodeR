# 会话交互改版设计（2026-10-15 用户确认）

## 用户需求（原话要点）
- 新版"没有了思考过程显示、编码工作显示"——过程被整轮折叠藏起（收工即收起）。
- "思考过程应该是先思考，思考完成后结果倒置到最前，以最精简的语言总结罗列" → 问卷确认 = **气泡顺序调整**（结果移到提问正下方、过程排后）。
- 过程可见性 = **最近一轮保持展开**（更早轮收起）。
- "每个会话要能方便快捷追溯（询问/回答的关键节点：问题、方案、审核结果、进度汇报）" → **右侧时间线/对话鸟瞰**：竖向从上到下、禁止占大量空间。
- "设计最科学符合手机横屏竖屏的交互逻辑"。

## 一、轮内气泡顺序（结果置前 + 完成后翻转）
- 目标轮内结构：`[用户提问] → [结果区] → [过程区（折叠头 + 思考/工具/中间正文）]`
- 结果区 = 轮末最终助手消息（现有 isResultCandidate 口径）+ 常显项（验收报告等）+ 轮末产物聚合块（TurnArtifactsBlock）
- 流式期间保持自然顺序（过程在上、正文在下）；**完成后落库重排即翻转**，加 placement 动画（animateItem ~220ms）顺滑换位
- **翻转后视角落点（重要体验设计）**：翻转发生时若用户视口靠近底部/跟随最新轮 → 动画后平滑滚动使「结果区顶部」可见（"先看结论"正合产品意图）；用户在别处回看历史则不打扰
- 实现点：buildChatItems 内 header 与 persistent 顺序对调；流式尾巴不动

## 二、过程可见性
- 折叠头展开态：`turnOverrides[turn.key] ?: (running || isLastTurn)` → 最新完成轮保持展开、更早轮收起、用户手动覆盖优先
- 与屏幕形态无关（内容结构逻辑）

## 三、右侧时间线 / 对话鸟瞰
- **位置：聊天内容区右缘 overlay**（放 AIChatPanel 的列表容器内）——竖屏=屏幕右缘；横屏/平板=聊天列右缘。**右栏工作台（终端/Git）开合、侧栏常驻、分栏拖动全部自动正确**（这是"一处实现全形态自适应"的关键）
- 形态：窄条视觉 ~16-20dp（透明背景仅绘节点；触摸热区可放宽）；不挤压内容宽度；节点小，落在右边距留白区，基本不遮挡正文
- 方向：从上到下 = 从早到晚
- 节点：每轮两基础节点——提问（主色实心点）/ 结果（细点）；验收报告（VerificationReport）特标色。**等距排列（目录式）**——长回复不会挤压其他节点
- 交互：点击节点 → `animateScrollToItem` 跳转 + 短暂高亮；**视口框**（当前可见区间）跟随高亮；滚动时 snapshotFlow(firstVisibleItemIndex) 轻量更新
- 高密降级：间距缩至 <3dp 时仅渲染"提问"节点；超密则再抽稀（保头尾）
- 键盘弹起 / 横屏矮宽：均随列表容器高度自适应
- 性能功耗纪律：静态绘制 + 滚动轻量更新；无动画、无轮询、无后台消耗
- v1 节点类型：提问 / 结果 / 验收报告（"方案、进度汇报"节点留 v1.1）
- 不做开关（保持极简），上线看反馈

## 技术要点
- `buildChatItems`（AIChatPanel.kt）：轮内顺序重排 + isLastTurn 展开
- 时间线：新 composable（agent/presentation/component 或 core/ui），输入 = 关键节点列表（chatItems 的 item index + 类型），输出 = 右侧条 + 滚动回调
- 翻转视角落点：轮完成检测 + `listState.animateScrollToItem(结果 index)`
- 无持续动画/轮询（性能功耗纪律）；动画仅交互与短暂过渡

## 四、消息长按菜单 → mini 悬浮窗（用户 2026-10-15 追加）
- 现状：长按消息弹出全宽底部大弹层（MessageContextMenuSheet，从屏幕底部升起）；用户要求改为**紧贴内容的 mini 悬浮小窗**。
- 目标形态：长按 → 消息旁弹出紧凑小卡片（宽 ~220-260dp，圆角/阴影，克制淡入+轻缩放 ~150ms）；全屏透明 scrim，点外关闭；条目紧凑（图标+短字），必要时可滚动；屏幕四边自动避让。
- 入口统一：①长按消息（锚定长按位置/消息边界）②操作行「更多」按钮（锚定按钮位置）→ 同一 mini 组件（替换 MessageContextMenuSheet 与 MessageActionsBottomSheet 的使用）。
- 实现要点：长按回调需带锚点坐标（onGloballyPositioned 记消息 bounds 或 pointer 手势取长按 offset）；overlay 放 AIChatPanel 根 Box 层（同现有悬浮层模式）。
- 内容保持现有能力集：复制/引用/解释/工作区查找/分享/选择文本（助手）+ 编辑/删除（用户消息）。

## 五、底栏模式胶囊 → 三图标按钮（用户 2026-10-15 追加）
- 现状：输入栏左下角单个模式胶囊（图标+文字「构建/计划/自动」，带底色）；点击弹选择层、长按创建定时任务。
- 目标：改为**三个纯图标按钮**（构建 Tool / 计划 Clipboard / 自动 Zap），去文字；**尺寸与右侧图标按钮完全统一（36dp 按钮 / 20dp 图标）**。
- 交互：点未选中图标 → 直接切换（保留「已切换」toast）；点当前模式图标 → 弹出原模式说明下拉（名称+描述+长按提示）；**长按 → 保持现状：正常进入现在的定时任务/定时 Plan 弹窗设置**（按当前模式分流，行为不变）。
- 视觉：当前模式=语义色（构建 success / 计划 primary / 自动 error），未选=onSurfaceVariant 灰；无底色，与右侧统一。
- 实现点：ChatInputBar.kt（模式区 700-790 改造为三图标；onModePillLongClick 现有签名与行为均不变）。
