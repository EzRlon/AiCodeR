## 设计要点（自会话摘要恢复）

- **三段式隔离（安全核心）**：①**只读抓取**（浏览商店内容）→ ②**安装**（写入本地，**不等于启用**）→ ③**启用**（用户显式激活；默认不激活）。「安装≠执行」。
- **统一数据模型**：技能 / MCP 服务器 / 专家团（编队）三类共用「商店条目」模型：名称、描述、作者、来源、版本、标签、统计（热度/点赞/下载/收藏）、详情链接、安装物定位。
- **源适配器**：每个源一个 adapter（列目录 / 搜索 / 取详情 / 取安装物）；源缺字段时对应排序与界面元素自动隐藏。
- **抓取引擎**：原方案=浏览器引擎抓 HTML；**2026-10-13 探测升级：claudemarket.ai 提供开放 JSON API**——`GET /api/skills`（分页/分类/来源/搜索）、`GET /api/skills/{slug}`（详情含 docsUrl/repoUrl）、`/api/categories`、`/api/search`；**无 Key、无速率限制、CORS 开放** → **优先走 API**，HTML 抓取仅作后备。
- **六种排序**：热度 / 点赞 / 下载量 / 人气 / 时间 / 收藏（源缺则隐藏）。
- **详情页双语**：用用户配置的模型 AI 翻译 + 本地缓存翻译结果。
- **源推荐**：技能 → claude-marketplace.com / claudemarket.ai；MCP → 官方 MCP Registry；专家团 → 先做「**从链接导入**」，随生态再上完整商店。
- **安装落点**：技能 → `~/.aicode/skills/`（或项目级）；MCP → 写入 mcp.json 配置（复用 manageMcp 的既有通路）；编队 → `~/.aicode/teams/`。
