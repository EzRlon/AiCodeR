## 三、崩溃根因与修复（已完成编译）

崩溃：`StringIndexOutOfBoundsException: Line 2 out of bounds. line count:2`，页面聊天（随记浮窗盖在聊天上）。

Retrace 落点：
- `MarkdownNoteCodeEditor.kt` 的 `MarkdownNoteController.prefixLine` / `wrapSelection`
- sora-editor `CodeEditor.setSelection(int,int)` 参数是 **(line, column)**，修复前传了**绝对字符下标**；2 行文档时下标 2 被当成第 3 行 → 崩溃。

修复（源码已改，编译通过）：
- `prefixLine`：编辑前取 `line`，插入后 `setSelection(line, prefix.length)`。
- `wrapSelection`：编辑前取 `leftLine/leftColumn`，插入/替换后 `setSelection(line, column + prefix.length)`。
- 撤销/重做不走 setSelection，不受此 bug 影响。

## 四、构建命令（aarch64 必须，已实测）

```bash
cd /root/workspace/AiCodeR
rm -rf /tmp/gradle-home-fresh && mkdir -p /tmp/gradle-home-fresh
ln -s /root/.gradle/caches /tmp/gradle-home-fresh/caches
ln -s /root/.gradle/wrapper /tmp/gradle-home-fresh/wrapper
GRADLE_USER_HOME=/tmp/gradle-home-fresh \
LC_ALL=C.utf8 LANG=C.utf8 \
JAVA_HOME=/usr/lib/jvm/java-17-openjdk-arm64 \
/root/tools/gradle-8.11.1/bin/gradle :app:assembleArmsoloRelease \
  --console=plain --no-daemon --no-build-cache --no-configuration-cache --max-workers=1 \
  -Pandroid.aapt2FromMavenOverride=/root/android/sdk/build-tools/35.0.0/aapt2 \
  -Dorg.gradle.jvmargs="-Xmx5g -XX:MaxMetaspaceSize=1024m" \
  -Pkotlin.compiler.execution.strategy=in-process
```

要点：
- Maven 的 aapt2 是 x86-64，会 `required file not found`；必须覆盖为 SDK 的 AArch64 aapt2。
- Gradle daemon registry 在 PRoot 上会 `canonicalize: Function not implemented` 卡死；用干净 `GRADLE_USER_HOME` + 关缓存。
- 同会话重复 `claude -p --resume 9d304073…` 会互相 `gradle --stop`；构建前确认只剩当前引擎，必要时暂停重复子树。
- 构建约 9 分钟；完成后 `apksigner verify --print-certs`，复制到 `~/workspace/`，用 `mcp__aicode_bridge__send_file` 发（token 可能 mismatch，失败就发路径）。
