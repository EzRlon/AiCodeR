## 三、待办（按优先级）

### P0 · 外部引擎子代理不建子会话（已诊断，未实现）
**现象**：Claude Code / Codex / OpenCode 三个引擎派出的子代理，侧栏没有分级会话、主会话无完成回执。

**根因（已核实）**：`newSubSessionEntity` / `upsertSession` 全仓只有 2 处调用，都在内置引擎 `TaskTool.kt:237,257`。三个 CLI 桥（`ClaudeCodeBridge` / `CodexBridge` / `OpenCodeBridge` / 基类 `AbstractCliBridge`）中 `newSubSessionEntity`、`upsertSession`、`SubAgentEvent` **全部 0 命中**——它们只把 `Task` 渲染成一条工具行。

**方案**：桥解析到 `Task`/`Agent` 工具调用时建子会话（`parentId`=当前会话、`subagentType`=成员名）→ 文本产出落该子会话 → 结束发 `SubAgentEvent(COMPLETED/FAILED)`。风险：CLI 子代理是引擎进程内部的，只能拿到「调用参数 + 最终 tool_result」，子会话内容为「任务描述 + 最终报告」，非完整过程。

- 构建目录被并发清理会导致 KSP 报「文件不存在」——`rm -rf app/build/generated/ksp app/build/kotlin` 后重跑
- 同一时段可能有另一路会话在跑 gradle（会互相 `--stop`），失败先确认不是环境争抢
- 迁移实际执行走 `core/db/IdempotentMigrations.kt`，`assets/migrations/*.sql` 只是审计留存

## 五、设计约定（本轮确立，后续须遵守）

1. **feature 边界基线**（`FeatureBoundaryTest`）：`feature/presentation` 不得新增跨 feature import；只许收缩不许扩张。跨 feature 组装用**插槽参数**由 `MainActivity` 注入（见 `MemoryGraphScreen.ledgerContent`）。
