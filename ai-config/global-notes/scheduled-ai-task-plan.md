# 定时任务 / 定时 Plan（长任务）——会话界面入口设计（评审稿 v1，2026-10-14）

## 需求（用户要点）
- 会话界面新增两个"进入定时"的入口：
  1. 顶栏「新建会话」长按 → 弹出选择；
  2. 底栏模式胶囊长按：Build → 定时任务；Plan → 定时 Plan（长任务，**开始前计划已完全备好**）。
- 要求做法科学合理；此前只定了入口形态，细节未定。本稿为细节设计。

## 现状锚点（已核实）
- 已有 `feature/schedule`（E5，提交 4a8f2e2）：**容器命令型**定时任务——`ScheduledTask{command, DAILY|INTERVAL}` + WorkManager + 设置页列表/编辑页。
- 主计划 #23：**「定时自主施工（保活版）：定时触发 AI 会话任务 + 保活联动（设计细化后实施）」**——本设计=其入口与交互细化。
- 可复用件：
  - 计划审批：`PlanApprovalPanel`「计划已完成」（按钮「批准并实施」，`approvePlanAndBuild()`）→ **新增第三按钮「定时执行…」是直插入点**（ChatInputBar.kt:1568+ / AIChatPanel.kt:1762）；
  - 后台授权：**已有**"AI 请求工具授权可从通知直接批准/拒绝"通道（channel `agent_permission`、按钮文案「批准一次」）；
  - 保活：`TerminalKeepaliveService`（dataSync 前台服务+静态启停）+ VM 内 WakeLock 续期（注释明确覆盖"超长任务"）；
  - 弹层先例：`AdaptiveModalBottomSheet` + `SettingsGroup/SettingsRow`（McpAddSheet 双项版式）；长按先例：会话行长按弹 SessionActionSheet；
  - 输入草稿由 VM 持有（面板可直接预填）。
- 约束：WorkManager 周期最小 15 分钟；AUTO 仅用户手动可入；升级 targetSdk 时 dataSync FGS 有 6h/24h 上限（build.gradle 已注明）。

## 1 概念模型：两种"定时 AI 工作"
| | 定时任务（轻量） | 定时 Plan（长任务） |
|---|---|---|
| 本质 | 到点让 AI 做一件事，跑完即止 | 计划先行、批准后无人值守的自主施工 |
| 入口 | 长按胶囊(Build)/顶栏+ | 长按胶囊(Plan)/顶栏+/计划审批面板 |
| 计划 | 不需要 | **执行开始前完整备好**（核心语义） |
| 时长 | 单会话一轮完成 | 长时（保活续跑；上限默认 12h【决策4】） |
| 重复 | 仅一次/每天/间隔 | 仅一次/每天 |
- 与存量"容器命令任务"**共用一张列表**（行内类型徽标）；模型向后兼容扩展（JSON 默认值，无需迁移）。

## 2 入口交互
### 2.1 顶栏「+」长按 → 「新建」选择层
- 单击不变（立即新建会话）；长按弹选择层，三行：
  1. 新建会话（=单击，兜误触）
  2. 定时任务——副标"到点执行一条指令"
  3. 定时 Plan·长任务——副标"先备计划，定时自主执行"
- 长按轻震动；点遮罩取消。

### 2.2 底栏模式胶囊长按（按当前模式分流）
- Build → 「定时任务」面板（模式预设=构建档）
- Plan → 「定时 Plan」面板（进入"计划先行"流程 §2.4）
- Auto → 「定时任务」面板（模式预设=自动档）：需显式勾选"执行时自动放行操作（风险自担）"才可提交【决策1】
- 为何是胶囊：模式语义在胶囊上，"长按=给该模式加时间维度"心智一致；发送键已占用语音长按，避免手势冲突。
- **可发现性**（长按天生隐蔽，必须补）：
  1. 模式选择层底部常驻小字：「长按胶囊：创建定时任务」【决策2】
  2. 定时任务列表空态补一行：「也可长按会话界面的模式胶囊创建」
  3. docs-site 模式页与定时任务说明同步一句（文档纪律）。

### 2.3 「定时任务」创建面板（轻量型）
- 字段：任务内容（多行；**草稿自动预填**，创建后可选清空草稿）｜（可选）快捷时间（每天 09:00/每小时/每 6 小时；**不填=待排期**，完整排期在设置页「排期中心」配置，见 §5）｜运行模式（可改）｜授权预勾（§3）｜名称（默认内容截断）。
- 提交校验（内容非空/时间有效/有工作区）→ 保存 → Toast「已创建：每天 09:00」+ 行内「查看/管理」→ 面板底部「管理全部定时任务 →」直进设置列表。

### 2.4 「定时 Plan」面板 + 计划先行流程
- **路径 A（主）**：面板 → "准备计划"→ 新开 PLAN 模式会话（目标预填）→ 聊完整 → 计划审批面板点**新按钮「定时执行…」**→ 弹快捷时间设置（可选，不填=待排期；完整排期/规则/编排在设置页 §5）→ 确认后**不立即执行**，入队为定时 Plan 并**存档计划正文**。
- **路径 B（辅）**：当前会话已有待批准计划时，长按 Plan 面板首项=「用当前会话的计划排期」→ 直接进时间设置。（已执行计划可否再排期【决策3】，建议 v1 仅"未执行"）
- **兜底**：允许"待备计划"先创建（先定时间）；到点计划未就绪 → 通知「计划未完成，本次跳过」不静默。
- 完成后：完成通知 + 摘要写回任务；运行会话保留（标题 `⏰ <名称> · 07-14 09:00`）。

## 3 执行侧（无人值守关键）
- **授权＝预授权清单制**（无人应答场景的替代方案）：
  - 创建时勾选类别：读文件✓｜网络✓｜写文件☐｜执行命令☐｜删除类☐（单独警示）→ 存为任务"授权档"
  - 运行时按档自动放行；**超出档位** → 任务暂停 + 走**现有通知授权通道**（批准一次/拒绝）→ 继续/跳过
  - 设置页加「定时任务默认授权档」（保守默认）；粒度 v1=类别级【决策5】
- **保活**：运行期启用 TerminalKeepaliveService + WakeLock 续期（复用）；通知栏显示运行状态+一键停止；服务通知文案区分场景。升级 SDK 的 dataSync 上限另案。
- **触发链**：WorkManager（复用 schedule 模块）→ 唤醒进程 → 建/复用会话（⏰ 前缀）→ 注入指令或"已批准计划正文" → 按模式+授权档跑 Agent → 回写记录 + 完成通知（可点进会话）。后台运行已被现架构支持（agent_permission 通道即为此设）。
- **通知**：开始（可关）/需授权/完成/失败，四类同任务同 ID 更新。
- **失败**：不自动重试（幂等风险）；结果附错误+会话链接。
- 与 E4 目标托管：长任务可叠加 E4 的"双模型验收+token 预算"（E4 独立实施，本设计留接口，不吸收）。

## 4 分期
- **v1**：两入口 + AI 型定时任务（ONCE/DAILY/INTERVAL）+ 预授权清单（类别级）+ 计划先行（路径A+「定时执行」按钮）+ 保活最小复用 + 列表统一展示
- **v1.5**：Auto 档、路径 B、待备计划兜底、通知进度
- **v2**：长任务续跑（每期继续直到完成）、工作流定时触发（#22）共用、粒度细化

## 5 设置页「排期中心」与数据同源（2026-10-14 用户补充）
- 原则：**一个任务一份数据**。会话界面负责"内容/计划"的创建，设置页负责"排期与规则"的管理；两侧读写同一存储（DataStore 任务列表），会话侧建好任务后设置页即时出现——「拉取」=同源直达，用户不需要二次录入。
- 排期模型扩展：`startAt`（开始）+ `endAt`（可选结束，过期自动停用）+ `repeat`（仅一次/每天/间隔）。「什么时候开始、什么时候结束」在设置页「排期」区配置；会话侧面板只在需要时提供"快捷时间"（不填=待排期，任务列表带角标）。
- 设置页任务详情分四区：排期 / 运行规则 / 编排 / 交接与轮转。

## 6 运行规则模式（含用户点名的「离开模式」）
- 三档核心模式：
  - **离开模式（全自主）**：不弹任何询问；按"授权档"自动放行，超档动作按配置处理（暂停等回/跳过记录）；歧义判断由 AI 自主决策并留理由记录。
  - **值守模式（关键点确认）**：仅高风险/不可逆操作或偏离计划时通知等待；其余自主。
  - **步步确认**：关键动作逐项批准（适合人在场）。
- 可叠加约束项：时间盒（到期停手交报告，默认关）｜Token/费用预算（超限暂停，复用预算面板）｜通知节奏（实时/每小时摘要/仅结束/静默）｜失败策略（停止/跳过/重试 N 次，默认停止）。
- 默认建议：定时任务=离开模式+仅结束通知；长任务=离开模式+时间盒 12h+每小时摘要。

## 7 自动交接（会话轮转·「接棒」机制，2026-10-14 用户要求自主设计）
- **底座已存在**（本次核实）：交接提醒（阈值默认 50% 可配）→「交接开新会话」= 生成接手摘要 + 新建「（接手）」会话 + 预置摘要消息 + 切换过去（`confirmHandoff()`）；另有自动压缩（`ContextCompactor`）与输入预算（`inputBudget`）。
- **轮转触发**（任一满足即接棒，赶在上下文退化/模型陷阱之前）：①助手轮数 ≥ N（默认 40）；②本会话压缩次数 ≥ M（默认 2）；③上下文占用 ≥ 阈值（默认 50%，沿用交接提醒设置）。
- **接棒流程**（复用 `confirmHandoff` 链路 + 五处增强）：
  1. 接手摘要增强：补 todo 快照 + 当前计划正文引用 + 未完成清单 + 关键路径/命令；
  2. 新会话创建走与「新建会话」完全相同的代码路径（`newSessionEntity/upsertSession`；非模拟触屏点击）；
  3. **继承补全**：模式（离开模式落到新会话）、编队（teamName）、授权档、**任务链 ID**（新增字段，列表里以链展示）；
  4. **自动续跑**：注入「继续推进」启动指令并自动发送（现状是预置摘要等用户发言，这里按规则自动化）；
  5. 旧会话标记「已交接至 XX」；轮转上限（默认 10 棒/任务）防失控；每次轮转写任务日志+通知（静默规则下只记录）。
- 与「离开模式」配合即实现无人值守接棒；「步步确认」模式下仍弹面板由人点。

## 8 任务编排（编队等）
- 编排区：**编队**（复用专家团，写入 `session.teamName`，接棒会话自动继承）｜模型覆盖（默认沿会话）｜子代理并发上限｜完成后动作（通知/归档；链式任务 v2）。
- 与工作流 P2（定时触发）同构：工作流执行时的编排即复用这套字段。

## 9 决策记录（2026-10-14 用户授权代选，标准=合理·科学·最优）
1. Auto 长按自动档：**做成**——需显式勾选「执行时自动放行（风险自担）」才可提交，默认不勾。
2. 可发现性提示：**按建议执行**（选择层底部小字 + 列表空态 + docs 三处齐补）。
3. 已执行计划再排期：**v1 不支持**（仅未执行计划可排期，防旧计划误当新计划跑）。
4. 长任务单次执行上限：**12h**（可配置）。
5. 授权清单粒度：**v1 类别级**（读/网/写/命令/删除），后续可细化。
6. v1 范围：**按 §4 v1 清单**（两入口 + AI 型定时任务 + 预授权 + 计划先行 + 保活最小复用 + 列表统一）。
7. 轮转阈值：**40 轮 / 2 次压缩 / 50%；接棒上限 10 棒**（全部可配）。
8. 离开模式超档动作：**默认暂停等回**（无人值守也不静默跳过，避免半成品）。
9. 通知节奏：**定时任务=仅结束；长任务=每小时摘要 + 需授权即时**。
