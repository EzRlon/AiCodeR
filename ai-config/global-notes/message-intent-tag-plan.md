# 「消息类型」标签功能设计（评审稿 v1，2026-10-14）

## 需求（用户要点）
- 会话输入区**底栏下方新增一个按钮**：为当前输入内容定义**类型**（如：反馈 / 新增计划 / 缺陷修复）；
- 类型不限编程方向——用户不一定只用来编程，需要更多通用方向；
- 要求：先总结汇总类型体系，再设计好功能。

## 一、功能定位（一个按钮，三层价值）
1. **对 AI**：把"这条消息是什么"显式告知模型 → 按类型调整处理策略（缺陷→先复现定位再修；方案计划→先出方案后动手；调研→先广搜再收窄；翻译→直出结果不废话）；
2. **对用户**：消息气泡上显示小徽章（一眼看清对话脉络）；会话内可改；搜索可筛（v2）；统计可看（v2）；
3. **对未来**：类型可挂「模板/检查清单」（缺陷=先要复现步骤；计划=结构化输出）、可驱动模式建议（方案计划→提示切 PLAN）、可进记忆/看板分类。领域中立，非编程用户同样受益。

## 二、类型清单（总结汇总；默认 13 项 + 「未分类」）
**编程方向（7）**
| 类型 | 说明 |
|---|---|
| 缺陷修复 | 有东西坏了：查因、复现、修掉 |
| 新增功能 | 做新能力/新模块 |
| 方案计划 | 先要方案/规划，再动手实施 |
| 重构优化 | 改结构/可读性/性能，不改行为 |
| 测试验证 | 补测试、跑验证、查回归 |
| 构建部署 | 打包、发布、环境与流水线 |
| 反馈意见 | 对产品/成果的意见（不一定马上改） |

**通用方向（6）**
| 类型 | 说明 |
|---|---|
| 调研研究 | 查资料、对比选型、出调研报告 |
| 写作编辑 | 文档/文章/文案的创作与润色 |
| 翻译润色 | 翻译与语言打磨 |
| 数据分析 | 表格、指标、可视化 |
| 学习问答 | 解释概念、教学式回答 |
| 日常自动化 | 例行任务、脚本、批处理 |

- 默认「未分类」；选过即用、发完重置（类型描述的是"这一条"）；
- 可自定义（v2）：改名/增删/隐藏、常用置顶（最近 3 个）。

## 三、交互设计
1. **按钮位置**：输入卡片内、底栏（工具行）**之下**新增一条**细标签行**（约 28dp 高）：左侧一个胶囊按钮「[标签图标] 类型：未分类 ▾」，右侧留空。点击弹出选择层。
   - 为何放卡片内而不放卡片外：卡片外一行会在软键盘弹出时与键盘区挤压冲突；卡片内贴底是既有结构最自然的落点（用户若坚持卡片外，可再议）。
2. **选择层**（bottom sheet，与模式选择层同风格）：顶部「未分类」；下分「编程方向 / 通用方向」两组，组内网格或两列列表（图标+名称+一行说明），点选即定、自动关层；已选项高亮。
   - 「方案计划」选中后，层内底部出现轻提示「配合计划模式效果更好」+ 一键切 PLAN（可关闭，默认出现）。
3. **发送后**：类型随消息落库；**用户气泡顶部显示小徽章**（图标+名称、弱化色）；草稿类型重置为「未分类」。
4. **修改**：点击自己消息上的徽章 → 弹同款选择层改类型/清除（无需重新发送）。
5. **AI 侧接法**：请求构建时，若最后一条用户消息带类型，在模型输入中加入一行**瞬态**说明（如 `（本条消息类型：缺陷修复）`，不入库、不显示于气泡）；同时在系统提示词加一个轻量片段（`45-message-intent.md`）说明各类型语义与应对方式；「未分类」不注入任何内容。
6. **视觉**：全部走主题 token（胶囊风格对齐模式胶囊）；中英双语；深浅主题适配。

## 四、数据与实现落点（带文件）
- **存储**：`AgentMessageEntity` 末尾追加 `intentType: String?`（沿用"仅 USER 行元数据"范式；**必须追加在表尾**——备份 DTO 映射按位置参数）；`AgentMessage.UserMessage` 加同名字段。
- **迁移 64**：`64_add_message_intent_type.sql` + Migration63To64（沿用现有幂等/容错范式）；`SCHEMA_VERSION 63→64`；`schemas/` 导出 64.json；备份链路登记（BackupSnapshot 系列）。
- **状态**：`AIAgentViewModel` 加 `draftIntentType: StateFlow<String?>`；发送链路把类型带入 `messagePersistenceUseCase.persist(...)`（加可选参数）。
- **UI**：`ChatInputBar.kt`（细标签行 + 选择层）；消息徽章在用户气泡组件（`MessageComponents.kt` 一带）。
- **提示词**：`assets/prompts/45-message-intent.md`（新片段）。
- **strings**：中英 `intent_*` 约 16 条。
- 迁移登记检查点：`MigrationLoader`、幂等迁移约定、release-pending 清单。

## 五、边界与原则
- **零负担**：不设默认类型、不阻塞发送、「未分类」永远合法；
- **不臆断**：AI 不主动复述"你标记了 XX"（除非与回答相关）；
- **领域中立**：编程/通用同权；默认集之外可自定义（v2）；
- 类型是"弱标记"：仅影响 AI 处理策略与组织，不改变权限/模式（除非用户点确认切换）。

## 六、分期
- **v1**：细标签行按钮 + 13 项选择层 + 落库（迁移 64）+ 气泡徽章 + AI 瞬态提示 + 提示词片段 + 中英文案；
- **v1.5**：徽章点改类型、计划模式联动提示、常用置顶；
- **v2**：自定义类型（`~/.aicode/message-types.json`，可导入导出）、搜索过滤（`类型:缺陷修复`）、统计计数。

## 七、决策记录（2026-10-14 用户授权代选）
