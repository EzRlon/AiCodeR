# 远程管理（MT 管理器同款 HTTP 方式）实施设计（2026-10-13 用户点名）

## 需求
设置中新增「远程管理」：手机端启动一个 HTTP 服务，电脑浏览器直接访问网页管理手机文件
（浏览/上传/下载/重命名/删除/新建文件夹）。对标 MT 管理器最新版「远程管理」，按 HTTP 网页方式实现。

- B4 批次规划过（「文件管理增强 + HTTP 远程管理（NanoHTTPD，MT 同款业务逻辑）」），因未排期而未开工。

## 设计（v1）
- **服务**：NanoHTTPD（org.nanohttpd:nanohttpd:2.3.1，轻量 ~50KB；需验证能否从 maven 拉取；
  失败备选：自写 ServerSocket 手写 HTTP，参照 MCP 回环先例，约 300 行）。
- **页面**：内嵌网页（assets/remote/index.html + JS 单页）：
  - 目录列表（名称/大小/时间/图标）、点击进入、面包屑、返回上级；
  - 多选、删除、重命名、新建文件夹；
  - 下载（浏览器原生）、上传（选择 + 拖拽）；
  - 移动端自适应。
- **API**（JSON）：
  - `GET /api/list?path=`；`GET /api/download?path=`（流）；
  - `POST /api/upload?dir=`（raw body + X-File-Name 头，或 multipart）；
  - `POST /api/delete`；`POST /api/rename`；`POST /api/mkdir`。
- **根目录**：v1 = 外部存储根（/sdcard）；工作区（~/workspace）作为快捷入口（细节实施时按现有
  文件管理能力的可访问范围定）。
- **入口（用户定，2026-10-13）**：合并到左侧栏「Web 预览」处——点击该行后弹出两个功能入口：
  ①「Web 预览」（原功能，进工作台预览）；②「远程管理」（新页面）。原功能保留，不再单独在设置里加重复入口。
- **安全**：仅局域网提示；服务运行时前台通知（保持存活 + 一键停止）；v1 无鉴权（同 MT），
  后续可选增强 PIN。
- **生命周期**：v1 服务随开关启停；App 进程存活期内有效（前台服务后续增强）。
