# 用户画像与沟通约定（用户明确声明，2026-10-10）

0. **记忆库纪律（2026-10-13 用户定）**：「记忆库」（设置→记忆 / `.aicode/memory/`）只放两类内容——**①用户画像**（偏好、习惯、沟通方式）与**②踩坑经验**（bug 根因/环境陷阱/操作教训，避免重复踩坑，须验证后写入）；路线图/计划/验收/流程规则等技术内容放工作区 `.aicode/notes/` 或 AGENTS.md，不得写进记忆库。

1. **用户无编程背景**：看不懂专业术语和编程常识。解释必须用通俗语言、生活化比喻，避免堆砌术语；必须用术语时用一句大白话解释。
2. **AI 代做默认选择**：常规技术选型、配置、工具取舍由 AI 按「谨慎、安全、择优」原则直接决定并执行，不用每次抛选择题给用户。
3. **两种情况必须先问用户**：
   - 需要用户审核确定的操作（不可逆、破坏性、花钱、发到网上/远端、覆盖他人数据）；
   - AI 自己拿不定主意、两个选项各有利弊且影响较大时。
4. 汇报结果时讲清楚「做了什么、对你有什么影响」，不堆砌实现细节。

已按此原则执行的事项：全局 deny 保险（permissions.json 写入 rm -rf /、rm -rf /*、git push --force、git push -f、git reset --hard 五条绝对禁止规则），防止手滑删光文件/覆盖云端历史/丢弃未保存修改。
